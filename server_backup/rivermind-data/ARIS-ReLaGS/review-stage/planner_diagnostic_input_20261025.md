# 诊断门重规划

GLM 已否决直接采集新GPU观测bank：support descriptor可能只是可见性加权离散化；新bank的随机映射和相机顺序也不能与历史R0因果比较。请据此设计一个严格 CPU-only 的最小诊断，使用当前可访问的 R0 NAG/nag_feat、二维 seg_map/features、相机和高斯几何，不读取GT、不重建NAG、不提取新特征、不启动GPU。

目标不是证明方法有效，而是判断：

1. 父子层级之间是否存在可重复的支持冲突或语义漂移代理；
2. 覆盖比例/边界/父子关系等descriptor是否提供超出节点可见性和面积的独立信号；
3. 哪个最小结果会让我们停止支持分桶路线，哪个结果才足以批准一次新bank采集。

请给出实际可用的输入接口、公式、无GT统计、伪代码和停止条件。必须区分可计算事实、代理指标和最终分割证据。考虑当前模型只有最终NAG，不能假称有ROFA前逐视角特征。最多提出一个诊断路线，优先利用2D mask投影到固定NAG的几何关联；如果该代理无法避免新的GPU渲染或候选重建，请明确说无法在当前资产上完成，提出最小新增资源。
