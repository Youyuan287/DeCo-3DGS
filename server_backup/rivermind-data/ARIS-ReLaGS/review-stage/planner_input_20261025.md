你是研究规划者。请充分展开推理，但最终输出控制在 3000 汉字以内。目标是寻找开放词汇三维分割中能够形成论文贡献的真实问题，不能只提出模块名。

## 已核查事实

1. 当前可接受的 ReLaGS HF-only 四场景宏平均为 64.0068%；当前研究对象是 LERF-OVS，不能混入 LERF-Mask 或 3D-OVS。figurines 作者 PT 63.2871 与自生成 R0 56.7254 属于不同产物，不能混成同一 baseline。
2. ReLaGS 的 `proj_gaussian_features` 已经做了：视角内 mask 到三维节点比例混合、可见性加权、跨视角 cosine 异常过滤和单向量平均。因此“没有利用多视角”是错误表述。
3. R0 最终模型已核验：nag/nag_feat，NAG 各层节点数 2102/467/179，特征 512 维；R0 文件 SHA256 已保存。生产输出没有保存随机 `pt_sp_label`、ROFA 前逐视角特征和 visibility，因此历史 R0 聚合无法精确回放。
4. 已完成 CPU/torch 算子检查：当前 outlier filter 对重复观测敏感；人工复制一个方向的观测可改变 mean_sim、sigma、keep 和 fallback；身份去重可恢复原输出。这只是算子性质，不是实际数据收益。
5. 已完成空间支持/排名/数量等控制：空间乘法、统一数量、排名和计数替换均不能作为当前主线；不能重复扫描 FCE/BSHRINK/HCONS 堆叠。
6. 新固定图观测采集的预检已通过：299 相机、598 个二维输入 hash 与节点 ID 对齐，非单例几何视角组存在（组大小 1/2/3/4/5），预算约 1.63 GiB；但实际 GPU 采集因 `thgs` 环境缺少 `diff_surfel_rasterization_trace_maxcontrib` 在首视角前停止，尚未产生观测 bank。
7. 已核查的近邻工作：MaskClustering 使用跨视角共识图；ConceptFusion 做局部/全局三维融合；OpenInsGaussian 涉及上下文特征和跨视角注意力。不能把“多视角聚合”“context”“attention”本身当作新颖性。
