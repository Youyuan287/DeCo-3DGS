# 独立审查 DeepSeek 方案

请审查下面的研究方案。不要执行实验，不要假称查阅外部论文。重点判断：支持描述/分桶/多原型是否真正区别于已有可见性加权、异常过滤、跨视角注意力和 top-k；是否有充分证据作为主线；固定图新 bank 的协议是否公平；最小决定性实验是否会把容量、阈值或随机性混入。最多提出三项核心反对意见，给出继续、只做诊断或停止裁决。

## 已知约束

- 目标是 LERF-OVS，四场景 HF-only 宏平均64.0068%；禁止混入 LERF-Mask/3D-OVS。
- 现有 ReLaGS 已有 mask比例、可见性权重、cosine异常过滤和单向量平均。
- R0最终NAG已核验，但没有历史ROFA前逐视角缓存；新固定图观测bank尚未成功采集，不能称恢复R0。
- 所有真实实验必须固定同一NAG、二维输入和evaluator；GT只能最终评分。

## DeepSeek方案

主线候选：支持可识别性与部件—父层级不可逆传播。

失败模式：同一节点同时接收对象内部、部件、遮挡边缘和背景渗漏观测；层级合并后父节点语义漂移且不可由子节点恢复。

核心假设：2D到3D丢失part-of、遮挡与覆盖支持关系，单均值把不可交换证据视为可交换，导致父节点语义漂移。

最小改动：投影函数输出support_descriptor（覆盖比例、边界距离、连通块/父子候选、可见性）；只在相同支持模式内平均，跨模式保留原型与冲突标记；层级合并输出证据集合而非单向量。

对照：历史单均值、同descriptor随机打乱、支持分桶、支持标签打乱；固定K、桶规则和阈值后，在四场景最终mIoU上比较。若支持分桶不优于随机分桶/打乱标签，或合并翻转率不降，停止。

补充候选：少数视角保护多原型；查询条件化证据集合匹配与弃权。DeepSeek认为两者容易退化成容量、top-k或阈值包装。
