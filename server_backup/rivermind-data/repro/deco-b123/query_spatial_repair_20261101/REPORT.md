## 失败解释与边界

207/208条发生空间修改，当前实现缺少可靠的“不修改”判据。B平均新增857/删除885个Gaussian，C平均新增604/删除2307个，D平均新增757/删除3530个。C的删除明显增加，与rank2/found退化相吻合；这支持“该规则过度缩减支撑”的描述，不构成排除所有其他原因的因果证明。

选中mask层级1/2/3比例：B 23.53%/36.14%/40.33%，C 34.47%/35.36%/30.17%，D 50.30%/28.77%/20.93%。文本规则较几何规则选择更多细粒度mask，但本实验不能证明这是唯一失败原因。

C优于D说明匹配文本优于这一错配控制；D没有匹配修正面积/粒度，因此不能声称已经单独隔离“语义贡献”。源证据稀疏采样、中心投影关联、>=10%重叠门槛与单mask投票，均可能限制新目标发现。特别是该局部重叠门槛本来就不能覆盖完全脱离当前支撑的物体，因此不能据此否定一般的池外候选生成问题。

结论：**当前“局部mask选择+多数票”实现失败，不支持将其写为有效空间重组方法。** max(A,B,C)的诊断oracle .709706提示个别空间修正确有价值，但未解决GT-free的安全选择；不得追加基于本轮结果挑阈值后改报主结果。

实现修复记录：正式运行前修正了独立部署脚本的PYTHONPATH；首个样本日志中的numpy整数JSON序列化错误也已修复。二者均未改变冻结评分/投票规则，最终208条来自一次完整成功运行。
