# LERF-OVS 第 2 步：候选重排器实验（leave-one-scene-out）

- 协议：4 折，每折 3 个场景训练、第 4 个评估；候选 = released top-5 pool；标签 = 逐候选渲染 IoU。
- 选择器：GBM 回归候选 IoU，每查询取 argmax（单候选选择）；gate 变体为预测增益超过 tau 才从 rank-1 切换。

## 主结果（逐查询平均 IoU）

| 方法 | 平均 IoU |
|---|---|
| DeCo main（gap 多标签） | 0.6396 |
| rank-1 单候选（不重排） | 0.5327 |
| 选择器（重排后取 argmax） | 0.5995 |
| 选择器 + gate | 0.5854 |
| 重排 + gap（多标签） | 0.6358 |
| oracle 单候选上限 | 0.7094 |
