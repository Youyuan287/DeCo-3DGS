## 2. 关键结构性观察（本轮的出发点）

把所有候选-查询打分写成一张矩阵：

```
S[g, c] = <f_g, t_c>
```

任何决策都只对**被边缘化的那个轴**敏感：

- **ScanNet**：对固定区域 g，在 c 上取 argmax → 决策对 `S[g,·]` 的**常数平移**不变
  （给整行加常数不改变 argmax）。因此能影响它的是**列（类）方向的偏置** `b_c`。
- **LERF**：对固定查询 c，在候选 g 上取 top-g → 决策对**整列加常数**不变。
  能影响它的是**行（区域）方向的偏置** `a_g`。

这是一个纯粹由"决策取哪个边缘"决定的结论，不依赖数据。它同时解释了：

- 为什么 **zR（逐类标准化）在 ScanNet 上 +5.62**：它正好去掉 `b_c`；[V]
- 为什么 **zR 在 LERF 上恒等于恒等变换**：单一查询时 `b_c` 是常数，对候选排序无影响；[H→V]
- 为什么 **C1（场景均值中心化）在 LERF 上中性（−0.08）**：它去掉的是所有区域共享的分量，
  不改变行方向的**差分**偏置。[R]

### 可检验的推论（本案的预测）

如果这个分解正确，那么：

- **P1**：给 LERF 加上"去行偏置" `a_g` 应当改变（并可能改善）候选选择；这是**从未做过**的一半。
- **P2**：给 ScanNet 加上同一个 `a_g` 项应当**严格不改变** argmax（解析上恒等）——这是一个
  干净的零对照，可以用来验证实现与推理。
- **P3**：同一估计量（双向中心化）在两个数据集上应给出"一个轴有效、另一个轴自动失效"的模式。

## 3. `a_g` 的可辨识性（关键设计问题）

`a_g` 必须**与查询无关**，否则会引入测试集依赖并违反 LERF 开放词表协议
（`lerf-openvocab-protocol`：逐 query 独立，禁止用场景其他类别做推断）。

可行且合规的估计：用一个**固定的通用词表** `V`（与评测查询无关），

```
a_g = (1/|V|) * sum_{w in V} <f_g, t_w>
```

这是纯离线、training-free、query-agnostic 的量，属于"区域对任意文本的平均亲和度"，
不是类别先验、也不使用任何评测标签。它与 C1 的关系：C1 减去的是**共享向量**（场景均值特征），
`a_g` 是每个区域**沿"平均文本方向"的标量投影残差**——前者去掉公共成分，后者去掉每个区域
自身的"泛匹配倾向"。两者正交，可叠加。

## 4. 与相邻工作的边界

| 工作 | 它做了什么 | 本方案的差别 |
|---|---|---|
| C1（DeCo，未发表） | 减场景均值特征 | 去掉公共向量；不区分区域 |
| zR（本轮归因） | 逐类 z-score | 只处理列轴；本文把两轴写成同一个估计量 |
| CSLS / hubness 校正 [L] | 用查询/邻居集合校正 hub | 需要查询集合；本文用**固定通用词表**离线估计，且只校正决策所边缘化的轴 |
| Query-Time Calibration [L] | 查询时校准 | 逐查询在线校准；本文是查询无关的离线统计量 |
| 局部对比（已否证） | 减邻域均值 | 相对量，去掉绝对语义；本文不改绝对量，只去行偏置 |

## 5. 尚未解释、但本轮不追的问题

- 13.7% vs 65.3% 的一致性断层（需要逐视角标注，成本高）。
- 细粒度目标缺失（需要 level 0/1 观测导出，已知受编码器掩膜数限制）。
- ScanNet C2-only 缺口。

## 6. 机会排序（初判）

1. **双向偏置分解**：解析清楚、成本最低、有零对照、能同时解释两数据集的失败模式。
2. 支持度条件化（按可见视角数收缩）：便宜，但只是可靠性加权，缺故事。
3. 成对偏好模型：机制清楚但未见正信号，成本中等。
4. 图信号高低频分离：成本高，且与局部对比同源风险。
5. 跨视角分歧建模：历史已多次尝试（M1/M2/M3），无新信息源前不再进入。
