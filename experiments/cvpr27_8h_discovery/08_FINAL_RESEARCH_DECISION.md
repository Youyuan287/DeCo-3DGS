# 08 — 最终研究判断

## 结论：**B- —— 解释性框架成立，方法学主张被 N1 否证**

（N1 之前是 B：线索尚有叠加可能。N1 之后，`a_g` 作为方法不再成立。）

不是 A（可直接围绕它写主创新），也不是 C（假设被否证）。

## 1. 本轮真正得到的东西

**一条可证伪的统一解释：**

```
S[g,c] = μ + a_g + b_c + r[g,c]
```

- 决策在 `C` 上取 argmax（ScanNet）→ 只看见 `b_c`；
- 决策在 `G` 上取 top-k（LERF）→ 只看见 `a_g`。

这条引理把一个长期困扰我们的不对称（zR 在 ScanNet +5.62、在 LERF 恒等；C1 在 LERF 中性）
变成了**同一个陈述的两个特例**。这是半年以来第一次有一个框架同时解释两边的失败模式。

**一个受控但幅度不大的新正结果：**

- LERF：`a_g` 校正使 macro 从 0.6401 → **0.6498**（+0.97 pp，逐查询 CI [+0.12,+2.50]），
  第二份词表 0.6534；
- 两个负对照都显著为负：同幅度随机置换 −5.6、支撑度收缩 −2.4；
- 26/208 条查询的选择被改变。

## 2. 为什么不是 A

| A 级要求 | 现状 |
|---|---|
| 解决一般性问题 | 引理一般，但方法只在 LERF 半轴有效 |
| 与先行的明确差别 | 与 CSLS/hubness 的差别只是"用固定词表估计"，属弱差别 |
| 机制可解释 | 是（加性分解 + 边缘轴） |
| 两数据集稳定收益 | **否**：ScanNet 侧无新增（= zR），LERF 侧 +0.97 |
| 回答"为什么别人没做" | 说得通（大家默认做特征侧归一化），但不足以支撑主贡献 |
| 无先行覆盖 | 未做 CSLS 受控对比，**不能断言无覆盖** |

## 3. 为什么不是 C

`a_g` 的效果不是噪声：随机置换与支撑度两个对照均显著为负，且效应方向在 5/6 的
（场景×词表）组合上一致。假设没有被否证，只是**证据强度不足以支撑主创新**。

## 4. 如果继续，把它变成 A 的条件（按重要性）

1. **未参与设计的场景上复现**（必须）——否则一切作废。
2. **与审计器叠加**：若 0.6711 → ≥0.678，`a_g` 才有资格进入方法章节；若只 +0.1 pp，降级为分析。
3. **与 CSLS/hubness 的公平受控对比**（必须）——否则"无先行覆盖"不成立。
4. 词表规模/语义域的稳健性（32/128/512；室内/户外）。
5. 给出 `a_g` 的一阶论证：为什么是"沿平均文本方向"而不是别的统计量。

## 5. 如果现在就要定投稿策略（建议）

**不要把"两轴偏置"当主线。** 现有最扎实的主线仍是判决审计（LERF 0.6711，CI 正，跨场/leave-out
稳健），两轴分解作为它的**分析章节**：解释"为什么审计在 LERF 有效、在 ScanNet 无效"，
并顺势给出 `a_g` 这个低成本增益（若叠加成立）。

理由：审计有 +3.13 且有多重稳健性检查；`a_g` 只有 +0.97 且场景非独立。用后者当主线，
正文的核心贡献会是一条初等引理加一个小增益，抗不过第一轮审稿。

## 6. 诚实的话

半年没有稳定核心创新，不是因为我们不够努力，而是因为**一直在分数层找"更好的分数"**。
本轮的分解说明：在 ScanNet 上分数层的收益是类别重标定（zR），在 LERF 上分数层几乎无利可图
（26 条查询、+0.97），真正的 +3.13 来自**决策层**。

如果还要找"A 级"，最可能的入口不是继续调分数，而是**决策层的一般化**：
什么条件下允许推翻既有判决、以及这个条件能否在 ScanNet 上以不同形式成立。
这与审计器同源，且有 +3.13 的实证基础。

## 7. N1 之后的修订判断

| 主张 | 状态 |
|---|---|
| 加性分解 `S = μ + a_g + b_c + r` 与"决策边缘轴"引理 | **成立**（代数），且解释了 zR/ C1 / LERF 的不对称 |
| `a_g` 作为可移除的偏置 | **不成立**：与语义质量正相关，减它会伤真物体 |
| `a_g` 单独接在证据上 +0.97 | 成立但无实用价值（低于审计器 0.6711） |
| `a_g` 与审计器叠加 | **−1.5，deep 改判归零**（α 单调破坏） |

因此本轮的科学产出是**一个解释 + 一个被否证的方法假设**，不是一个新的 SOTA 组件。

可以写进论文的只有一句分析性陈述：
"决策在哪个轴上边缘化，就只对那个轴的加性项敏感；因此跨类别校准（zR）与跨候选校准
（行偏置）不能互相替代。而区域行偏置与语义质量不可分，故 LERF 侧的分数层校正空间很小。"

这句陈述的价值在于**解释审计器为什么必须在决策层工作**——它把 +3.13 的实证结果
放到了一个更清晰的理论位置上。但它不是方法贡献。

## 8. 由 E7 得到的方向修正

审计器在**自己的选项集**上已用掉 88.6% 的天花板（0.6711 / 0.6751）。这意味着：

- 决策层门控、阈值、bootstrap 形式的任何改动，上限约 +0.4 pp；
- 要让 LERF 明显超过 0.675，唯一出路是**新增一个与现有三选项不相关的高质量候选**；
- 而这正是此前失败的方向（多证据保留、局部对比、粗细分）——它们失败的原因不是"选择器不行",
  而是"新候选本身不比 released 好"。

于是本轮把问题精确定位为：**在什么条件下，逐视角证据能产生一个比 released 更好的候选，
且该候选与 C / mask 不相关？** 这是一个比"共享语义"具体得多、也可证伪的问题。

## 9. 修正后的下一主攻问题（取代 8 节）

E8 显示：单候选层面 22.6% 的查询池中就有明显更好的解，但三种训练-free 信号只找到了 19 条。
**所以本轮的最终结论不是"没空间"，而是"空间在识别，不在校准"。**

下一阶段唯一值得投入的问题：
> 在不使用 GT 的前提下，如何从 released 候选池里识别出那个 IoU 明显更高的候选？

已知的三条失败路径（证据均值、邻域对比、行偏置）说明：**答案不太可能来自对文本相似度的
再加工**。若要继续，应转向与文本相似度**正交**的信号（例如二维掩膜的跨视角几何一致性、
可见质量、遮挡结构），而不是继续调整余弦分数。
