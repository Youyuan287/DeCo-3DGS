# 04 — 主攻方法设计：两轴加性偏置（H1）

## 1. 一句话

开放词汇 3D 分数 `S[g,c] = <f_g, t_c>` 里混着两个与查询无关的**加性**偏置：
区域泛匹配倾向 `a_g` 和类别整体亲和度 `b_c`。**决策只对它边缘化的那个轴敏感**，
所以"该去哪个偏置"由决策形式决定，不是超参数。

## 2. 形式化

设场景内区域集合 `g ∈ G`、查询/类别集合 `c ∈ C`。

**引理（决策轴）**：设 `D` 为在 `C` 上取 argmax 的决策。对任意只依赖 `g` 的 `a_g`，
`argmax_c (S[g,c] − a_g) = argmax_c S[g,c]`；对在 `G` 上取 top-k 的决策，
`argmax` 同理对只依赖 `c` 的 `b_c` 不变。

证明：两式都只是在被比较的维度上加同一个常数。∎

由此：
- **ScanNet**（逐 root 在 19 类上 argmax）→ 只能被 `b_c` 影响 → 去 `b_c`。
- **LERF**（单查询在候选上 top-g）→ 只能被 `a_g` 影响 → 去 `a_g`。

## 3. 估计量

```
a_g = < f_g , t̄_V >,   t̄_V = mean_{w∈V} t_w / ||mean||      V = 固定通用词表（与评测无关）
b_c = (1/|G|) Σ_{g∈G} S[g,c]                                  场景内列均值
S'[g,c] = S[g,c] − α·a_g − β·b_c,    α = β = 1（不做调参）
```

- `V` 用两份**互斥**的固定词表（各 128 词，代码内写死），用于稳健性对照；
- `a_g` 完全离线、query-agnostic、training-free，不接触任何评测查询或标签；
- `b_c` 就是 zR 的均值项；zR 还额外除以类标准差，本轮要单独测这一项是否必要。

## 4. 与已有工作的差别（必须写清楚）

| | 去的是什么 | 依赖查询集合？ | 作用于哪个轴 |
|---|---|---|---|
| C1 场景中心化 | 场景**共享向量** | 否 | 所有区域相同 → 对行差分无效 |
| zR | 列均值 + 列尺度 | 否（场景内） | 列 |
| CSLS / hubness | 邻域/查询集合校正 | **是** | 行 |
| Query-Time Calibration | 在线校准 | 是 | 视方法而定 |
| **本文 `a_g`** | 每个区域沿"平均文本方向"的标量投影 | **否（固定通用词表）** | 行 |

**诚实评估**：ScanNet 那一半是已知的 zR，不是新结果。新东西只有两件——
(a) "按边缘轴校正"的引理，把两半统一成一句话；(b) LERF 的行偏置项 `a_g`，此前未做。
因此本方向的**上限是 B 级（高潜力线索）**，除非 LERF 半轴出现稳定增益。

## 5. 预测（先定后跑）

- **P1**：LERF 上去 `a_g` 应改变候选选择；若同时提升 mIoU，说明行偏置真实存在。
- **P2**：ScanNet 上去 `a_g` 对 argmax **严格无影响**（解析恒等）。这是实现正确性的零对照。
- **P3**：`E0_sup`（按可见视角数收缩）不应复现 `a_g` 的效果；若复现，说明收益来自支持度而非偏置。

## 6. 对照矩阵（LERF）

| 变体 | 目的 |
|---|---|
| released | 官方基线 0.6401 |
| E0 | 只用逐视角证据（无偏置校正） |
| E0_a | 去 `a_g`（词表 A） |
| E0_a2 | 去 `a_g`（词表 B，互斥词） |
| E0_arand | 把 `a_g` 随机置换（**同幅度**对照） |
| E0_sup | 按可见视角数收缩（H2 混杂对照） |

辅助读数：每个变体相对 E0 改变了多少比例的查询选择（`diff_*`），以及 `a_g` 与可见视角数的相关。

## 7. 停止条件（跑之前写死）

1. 若 `E0_a` 与 `E0_arand` 无显著差异 → 行偏置不成立，H1 降级为解释性框架，停止。
2. 若 `E0_a` 有效但 `E0_sup` 同样有效 → 归因于支持度，不是偏置，停止。
3. 若改变选择的查询比例 < 10% 且方向不一致 → 视为噪声，停止。

## 8. 已知的实现风险

- `a_g` 与可见视角数相关（figurines 上 r=0.55），必须用 `E0_sup` 排除。
- 位移幅度若不归一，不同词表的比较会被量级主导（已改为 `z(a)·sd(S)`）。
- 同一 root 下的多个候选共享同一 `a_g`，行偏置对它们不可分——这是粒度限制，不隐瞒。
