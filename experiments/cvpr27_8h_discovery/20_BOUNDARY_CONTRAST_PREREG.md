## 1. J 的定义（冻结）

对 unit `u = (scene, image, prompt)`、候选 `c = (level ℓ, cand_id)`：

1. `sims[k] = vlm.compute_similarity(snag.feat[k])`，`snag.feat` 对应 level `{1,2,3}`。
   candidates 的 `level ∈ {2,3}`，故 `k = ℓ-1`。
2. 逐高斯亲和 `a(g) = sims[ℓ-1][ labels[ℓ][g] ]`（`labels = snag.labels`，4 层）。
3. 渲染该视角的逐像素亲和：`_semantics[:,0] = a`，取 `render(...)["semantics"][...,0]`
   与 `["alpha"]`，**按 alpha 归一化** `a_v(p) = sem/α`（`α<1e-3` 处记 nan）。
4. 候选掩膜 `M = render({g : labels[ℓ][g] == cand_id})[:,0] > 0.5`。
5. 内点 `I = erode(M, w)`，外环 `O = dilate(M, w) \ M`。
6. `J = mean_{I} a_v − mean_{O} a_v`。

**冻结参数**：`w = 5`（像素）。敏感性 `w ∈ {3, 9}` 只作报告，**不得用于挑选**。
`η = 1`（融合权重，先验取 1，不调）。

**无效条件**（任一成立则 `J = nan`）：`|M| < 20 px`、`|I| < 20 px`、`|O| = 0`、
`M` 内 α 归一化失败像素占比 > 50%。

## 2. 判据（三条，全部先写死）

**B1｜方向（必要条件）**
在 `area>0` 的行上，unit 内 `ρ(J, IoU)` 的均值 ≥ `ρ(score, IoU)` 的均值 = **0.475**，
且配对 bootstrap（unit 重采样，2000 次）的 95% CI 下界 **> 0**。

**B2｜判决（决定性）**
`z(score) + 1.0·z(J)`（J 无效行的 z(J) 记 0）的 nested macro **≥ 0.6079**，
且相对 `z(score)+z(log area)` 的配对 bootstrap 95% CI 下界 **> 0**；
同时对 `0.5982`（非空对照）也要 ≥。

**B3｜机制（排除混入）**
在 `area>0` 且 J 有效的行上，把 `log area` 与空渲染标志同时回归掉之后，
`ρ(J, IoU)` 的偏相关 95% CI 下界 **> 0**。

**Kill 规则**：B1 不过 ⇒ "粒度可由边界对比识别"在这个场上不成立，
本命题停止，写成能力边界（不得改口径重跑）；B1 过而 B2 不过 ⇒ 记为
"J 有信息但不转化为判决"，只作消融。

## 3. 预注册的预测（跑之前就写下来）

按 §0 的结构，**我预期 B2 不过**，理由有两条，都可事后检验：

1. 逐像素亲和是**逐簇分段常数**（`a(g)` 由簇号查表得到，簇内没有更细的结构）。
   于是 J 退化为"本簇分数 − 相邻簇的像素加权分数"，即 `local-contrast-negative`
   已收盘的 Eknn 族（随机参考与 kNN 同分，损害来自减掉参考均值）。
   可检验推论：J 与"外环簇分数均值"高度相关（|ρ| > 0.8），且与 score 的相关 **> 0.6**。
2. 46.5% 的行渲染为空，J 在这些行上无效，而这正是现任最差的地方；
   J 无法经这些行提供增益，宏观天花板被压住。

**若 B2 反而通过**，说明边界对比携带了簇分数里没有的信息（与预测 1 相反），
那才是值得写进论文的发现，届时再设计第二臂（逐视角 per-Gaussian 投影特征）。
