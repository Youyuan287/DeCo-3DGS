# 09 — 下一步最小实现计划

按"信息量 / 成本"排序。每项都写明**决策规则**（跑完怎么判断），避免无限迭代。

## N1 ✅ 已完成（负结果，2026-11-03）：`a_g` 把审计器 0.6711 打到 0.6564

**做什么**：重新导出 witness，写入候选的 root region id；在证书里对每条证词减去
`a_g(region)`，其余（配对差值、半样本多数、范围支配）完全不变。
**成本**：需改 `lerf_witness_certificate.py` 的 witness 读取 + 重新 dump 一次（约 30–40 分钟机器时间）。
**基线**：审计器 0.6711（training-free）。
**实际结果**：N1a 0.6564 / N1c 0.6568，α 单调破坏，deep 族触发归零 → **判为负结果，停止**。
`a_g` 与语义质量不可分，是本案的关键发现（见 05 §7）。

## N2 未参与设计场景的复现 —— 决定整个线索是否成立

**做什么**：在 3D-OVS（已有 OccamLGS 场）或任一未参与 LERF 调试的场景上跑同一估计量。
**成本**：3D-OVS 受场分辨率限制（level-1 天花板 0.7735），只能作为"是否出现同向收益"的定性检验，
不能作为主结果。
**决策规则**：同向为正 → 保留；为零或负 → 该线索降级为"LERF 特例"。

## N3 与 CSLS / hubness 的公平受控对比 —— 决定新颖性

**做什么**：三种行轴校正并排：(i) 本文 `a_g`；(ii) CSLS 式（用同场景其他**候选**作邻域）；
(iii) query-time 校准。同一候选、同一融合、同一词表规模。
**关键**：CSLS 需要查询集合，因此必须限制在"同一查询的所有候选"内，不能跨查询——这正好是
本文与它的真实差别所在，必须显式测出来。
**决策规则**：若 (ii) 与 (i) 无显著差异 → 无新颖性，停止。

## N4 词表稳健性

32 / 128 / 512 词，室内 / 户外两组。**先定后跑**：只报告，不选最好。
**决策规则**：若符号随规模翻转 → 说明是噪声，停止。

## N5 ScanNet 侧的零对照（实现正确性）

在 10 场景上数值验证 `argmax_c (R − a_g) == argmax_c R`。
**成本**：<1 分钟。**作用**：把引理从"显然"变成"已验证"，并可在论文中作为方法正确性检查。

## 不建议再做的

- 任何形式的局部对比 / 邻域差分（已两数据集否证）。
- 任何需要 GT 参与选择的重排器（违反 training-free 与协议）。
- 继续在 LERF 上扫描 α、λ、top-k 找更好数字（测试集调参）。
- 重新训练场或重编码特征（成本高、且已有证据表明瓶颈不在这一层）。
