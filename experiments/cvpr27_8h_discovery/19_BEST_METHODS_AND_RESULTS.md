## A. 两个能用的方法

### A1 列轴校正（ScanNet）：逐类标准化

```
S'[g,c] = (S[g,c] − mean_g S[g,c]) / std_g S[g,c]
```

| 配置 | 19 类 mIoU |
|---|---:|
| raw released | 40.36 |
| **+ zR** | **45.98（+5.62，CI [+2.86,+8.40]，9/10 场景胜）** |
| + zR + 逐视角证据 E0（**正确文本库**） | **47.49（+1.51 over zR，逐场景符号混合，未做显著性）** |

- **适用条件**：决策在**类别轴**上做 argmax。
- **必然无效的地方**：LERF 单查询——列常数不改变候选排序（可证）。
- **⚠ 口径修正**：旧记的 `48.77` 是**错误文本空间**的产物（证据脚本用了
  `text_features(...)`，released 用的是 `text_bank.npz`，同类名余弦仅 0.495）。
  **论文必须写 47.49。**

### A2 判决证书（LERF-OVS）：等大小集合的配对改判

对同一查询的现任 `A` 与挑战者 `B`（**两者大小相同**）：

```
E_v(S) = max_{c∈S} a_v(c)                  # 视角 v 对集合的支持
δ_v    = E_v(B) − E_v(A)
半样本重采样 300 次，P(mean δ > 0) ≥ π  →  改判
```

| 配置 | macro | 说明 |
|---|---:|---|
| released | 0.6401 | 官方锚点，逐位复现 |
| **证书（π=0.5）** | **0.6711** | **+3.13，CI [+0.0114,+0.0548]** |
| 5 帧视角簇重采样 | 0.6711 | 排除相邻帧伪重复 |
| 10 帧簇 | 0.6675 | 同上 |
| deep 族 | 0.2914 → **0.6515** | 触发 6/25 |
| found 族 | 0.8316 → 0.8275 | 仅 3/129 触发，基本不动 |

- 触发 19/208（9.1%）。
- **结构定理（重要）**：`B ⊇ A ⇒ δ_v ≥ 0` 恒成立，因此本证书**只能比较等大小集合**，
  不能判断"该不该扩充集合"。LERF-Mask 上嵌套使用必然崩（0.7313 → **0.4604**，p 多为 1.00）。
- **适用条件**：逐视角证据强 + 等大小替换 + 同 query。

### A3 增量生长（LERF-Mask，弱）

对 `A={1}`，逐个判断"第 k 个是否值得加入"（非单调，绕开 A2 的限制）。

| π | macro |
|---|---:|
| 0.5 / 0.7 | **0.7591**（gap 0.7313，+2.78） |
| 0.9 | 0.7116（完全不生长） |

**诚实判定：+2.78 只来自 1 个 prompt（rubber duck），不能当泛化证据。**

## C. 可测量的机制事实（写论文时最有价值）

| 事实 | 数字 | 含义 |
|---|---|---|
| 分数与范围几乎不相关 | corr(Δscore,Δarea)=**+0.19**；Δscore/ΔIoU=0.42；Δarea/ΔIoU=0.46 | 二者**互补**，不是替代 |
| 二者相加有效 | z(score)+z(log area) = **0.6079** vs rank1 0.5565 | 仍是单候选，**低于并集 0.6401** |
| 跨视角"一致性"是反向信号 | `mwp_conf` AUC **0.465**、`agree` **0.442** | 一致性先验在 OV-3D 方向错了 |
| 被错过的正确候选更大 | 面积 **7×**、可见视角 +36%、分数 **−0.038** | 文本分数系统性偏好碎片 |
| 两数据集信息分布相反 | LERF 逐视角强；ScanNet 逐视角弱（更正文本库后 E0 25.30 vs released 40.36） | 决定"在哪一层融合" |
| 重叠度不解释收益 | corr(overlap, gain) = **−0.677** | E20，反向 |
| 轴边缘化引理 | 行常数不改 argmax；列常数不改 top-k | 解释 zR 有效/C1 中性 |

## E. 三个必须记住的口径教训

1. **文本空间混杂**：证据脚本与 released 用了不同编码器（同类名余弦 0.495）。
   ScanNet 的 `48.77` 必须改为 **47.49**。这是本轮最严重的一次自我纠错。
2. **二维布尔掩码拍平**：`x[ok]` 把二维数组拍平，`mean(0)` 变成全局均值，
   导致某版基线 36.96 而非 48.77，Sinkhorn 假性 +3.75。
   **规则：任何"新算子超过基线"先核基线是否等于已知锚点。**
3. **协议可比性**：LERF-OVS 可与已发表同表（有前提）；**ScanNet-10 不能**——
   与 OpenGaussian 唯一实质差异是"低不透明度点剔除"（σ(opacity)<0.1），未对齐前不可并列。

## F. 如果现在写论文，能主张 / 不能主张

**能**
- 一条原则（轴边缘化）+ 两个实例（列轴校正、集合级证书）+ 两处**可证明的零结果**。
- LERF-OVS：+3.13，CI 正，簇重采样稳健，分族有解释。
- ScanNet：zR +5.62（同场景、同读端、9/10 场景胜）。

**不能**
- 不能声称"两个方法同时提升两个数据集"——它们的作用轴相反，且都有结构性零结果。
- 不能声称通用性：4 场景非留出；ScanNet-10 非完整基准。
- 不能用 48.77；不能把 LERF-Mask 的 +6.39 余量说成方法收益（够不到）。
