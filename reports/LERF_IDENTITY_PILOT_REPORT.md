## 2. 关键发现（探索性，按预注册要求原样报告）

### 2.1 原始一致性 agree 是坏的，甚至反向

- agree（覆盖观测两两余弦均值）在 valid 上 AUC 0.460 [0.408,0.514]，deep 族 0.377 [0.241,0.500]——**低于随机**。
- 原因：观测特征未中心化，所有观测共享一个强场景均值分量，"一致性"实际测的是场景共性而非物体身份；它在 V 中把 rescue 拖到 0.036。
- agree_top（最相似 3 视角间一致性）好得多：valid 0.745、hard 0.584。

### 2.2 居中后出现真实的、与尺寸无关的跨视角信号

预注册变体 Vc = z(id_mean_c)+z(agree_c)（生产口径：特征减 raw_mean）：

| 特征（hard, n=55） | raw AUC | 对 log n_points 残差化后 |
|---|---:|---:|
| Vc | **0.807 [0.749,0.861]** | **0.758 [0.694,0.822]** |
| id_mean_c | 0.785 [0.731,0.836] | 0.590 [0.515,0.664]（尺寸混杂） |
| agree_c | 0.739 [0.678,0.798] | **0.732 [0.644,0.818]**（尺寸独立） |
| agree_top | 0.584 [0.512,0.660] | — |
| area_ratio（既有尺度先验，参照） | 0.881 [0.835,0.925] | — |

- **居中后的跨视角一致性 agree_c 是唯一在控制尺寸后仍保持强判别力的证据**（0.732），这是本 pilot 最有价值的技术发现：身份信号确实存在，但必须先去场景均值。
- Vc 在 cross-root hard 上 0.792 [0.725,0.850]、deep 0.768 [0.680,0.852]、found 0.877 [0.833,0.916]（对易查询无伤害）。
- **但 Vc 的 rescue 只有 0.382 [0.255,0.509]**（门控要求 ≥0.45 且 CI 下界>0.30），且 AUC 仍低于尺度先验 area_ratio 的 0.881——身份证据目前没有超过"面积/观测数"这个旧先验，只是提供了**尺寸之外**的增量信息。

### 2.3 观测级身份特征在叶节点上大量回退

- `fallback_root` 查询 108/208（52%）：多数叶候选的覆盖观测 <3，按预注册回退到整个 root 区域的观测——叶级身份实际是区域级。跨 root（46/55）的结论可信，兄弟叶判别要等 Phase B。

## 3. 对创新点的影响

1. **"候选级跨视角一致性"作为新颖项成立，但形式必须是居中特征的一致性**（raw 版本是反向信号）。这修正了我们在文献调研里对 (b) 项的设计。
2. **身份证据单独不足以超过尺度先验**（hard AUC 0.807 vs 0.881；rescue 未过线）。但两者互补：size 管"小干扰块"，agree_c 提供与尺寸无关的身份判断——组合的潜力仍未验证（本 pilot 未预注册该组合，不得事后宣称）。
3. 门控失败的原因不是信号不存在，而是**决策规则（argmax/等权 z 和）太粗**：AUC 0.807 与 rescue 0.382 的落差说明问题在"用证据做选择"这一步。
4. 依预注册纪律，本轮停止；若要继续，必须**登记新的 pilot v2**（预注册 Vc 为主、加入 rescue 导向的决策，如 top-1 vs 挑战者的边距检验），不得修改本轮结论。

## 4. 诚实的局限

- 困难子集仅 55 条（deep 19 条），置信区间宽；4 场景统计强度有限。
- 报告中列出的 Vc/agree_c 为预注册的**次要报告项**，未用于门控判定；任何基于它们的新结论都必须走新一轮预注册。
- area_ratio 与观测数量本身是尺度先验，对"小物体正确"的查询有系统性风险（前面证据审计已量化）。
- 观测特征由 root 区域掩码混合而成，叶级分辨率不足（108 条查询回退），Phase B 才能解决。
