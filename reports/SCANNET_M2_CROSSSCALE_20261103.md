# M2：跨尺度一致性是不是区域质量的信号

日期：2026-11-03
脚本：`analysis/scannet_m2_crossscale.py`
产物：`results/scannet_m2_crossscale_20261103/`（每场景 json / log / regions.csv / feats.npz）
服务器：`/root/rivermind-data/repro/deco-b123/scannet_sam_density_20261103/m2out/`

## 假设

同一个三维区域，用 merge_proj 实际使用的三个 mask 层级（level 1/2/3）各估一次特征：

- 如果区域语义是真的 → 应该**尺度不变**，三个估计的方向应该接近；
- 如果区域是靠上下文撑起来的（窗嵌在墙里、桌面摆着家电）→ 小 mask 切掉上下文、大 mask 吞进上下文，
  特征会随尺度漂移。

于是 `agreement(f_L1, f_L2, f_L3)` 应该与区域纯度正相关，并且可以作为训练-free 的区域置信度。

**预注册的判死条件**：H1（agreement 与纯度 Spearman 相关）为零，且 H2（agreement 预测"不纯区域"的 AUC）≈0.5
→ 跨尺度一致性不是信号，这个方向关闭。

特征完全用管线自己的 `proj_gaussian_features(root_partition, mask_level)`：
同分区、同编码器、同 ROFA，只换 mask 层级。GT 只用于给区域打分。

## 判读

**假设被否证，且方向是反的。**

1. 原始一致性挤在 0.94–0.96，方差极小；与纯度**弱负相关**（三个场景都是负号，只有一个显著）。
2. 去掉场景均值之后（这是必要的，因为记忆里已经有"场景共享语义余弦 0.69–0.76"的前车之鉴），
   相关系数回到 0 附近，AUC 0.496–0.515 = 抛硬币。
3. 三个场景的符号不一致（raw 全负，centred −/+ +），说明连方向都不稳定。

## 为什么失败：三个层级是嵌套的

level 1/2/3 来自**同一批 SAM proposal** 的不同尺度过滤（`masks_s / masks_m / masks_l`），
`proj_gaussian_features` 又把几乎同一批高斯按三个 mask 集合聚合。

所以三个"观测"并不独立——它们共享同一份渲染权重、同一批高斯、同一套 CLIP 特征，
只是 mask 边界略有差别。余弦 0.95 是**构造出来的**，剩下的 5% 是噪声。

这和 RIPA 的退化、以及跨视角一致性"一致地错"是同一个结构性问题：
**要测一致性，前提是几个观测的误差相互独立；嵌套尺度不满足这个前提。**

## 还剩一个版本（要不要做由你定）

唯一能让误差真正独立的做法：用**不同的分割参数**（或不同输入分辨率）重新编码一次 mask 集合，
在同一个重建场上比较两套独立特征的一致性。这才是真正的"重复观测"。

成本：重编码一个场景约 30–40 min（SAM + CLIP），特征侧还要重算一次聚合。
而且密度探针已经证明换 pps 会给出不同的 mask 集合（58 → 149 → 196 张），
所以这个版本在机制上是成立的，只是贵。

但我倾向于**不做**：因为如果它成立，它给出的仍然是一个"区域置信度"，
而 M1 已经证明区域纯度不是分区上限的约束；它最多是一个读端的软权重，
而这个位置已经被审计器占着（0.6711，CI 过零）。

## 结论

跨尺度一致性在这条管线里不是信号，原因可解释且结构性（层级嵌套 ⇒ 观测不独立）。
按预注册条件关闭。如果将来要重开，前置条件是**独立观测**（不同分割参数或不同分辨率），
不是再换一个一致性公式。

## 限制

- 3 场景，root 单位 145–264 个；scene0347 的区域数偏少（195 单位，筛掉无观测的）。
- 一致性只在特征方向（cosine）上测；没有测幅值/置信度。
- 区域纯度用最近 GT 点赋类，与管线自身的 GT→高斯映射一致。
