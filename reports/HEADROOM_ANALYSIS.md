当前最好：**gateE 0.6760**（B0）。主结果不是终点，下面是可量化的剩余空间与已排除的路线。

还没有系统性地做“加对第二个候选”。

## 2. 被忽略的轴：2D mask 的“选择”与 2D/3D 取舍

把 GT 最佳 2D mask 直接提升到 3D（oracle 上界）与当前 3D 选择对比：

| 族 | n | 3D gateE | 2D GT-best lift | 差 |
|---|---:|---:|---:|---:|
| found | 124 | **0.8312** | 0.6654 | −0.166 |
| rank2 | 36 | **0.6402** | 0.4726 | −0.168 |
| **deep** | **19** | 0.6607 | **0.8247** | **+0.164** |
| **recall** | **29** | 0.0198 | **0.2352** | **+0.215** |

如果按族 oracle 地在 2D/3D 之间选，macro 约 **0.7145**（vs 当前 0.676，+3.9）。
也就是说：**deep/recall 的瓶颈不是 3D 表示，而是“选哪张 2D mask”以及“何时信 2D”。**
found/rank2 则应该继续信 3D。

### 已排除：用跨视角特征一致性选 mask
在查询视角按 `z(text)+λ z(cross-view support)` 选 mask，再提升：
text 0.4598、xview(0.5) 0.4003、xview(1.0) 0.3038、support-only 0.0251。
**一致性会把共享/背景 mask 选出来**，与之前“一致性不是身份”的结论一致。不要再用特征一致性选 mask。

### 下一步（有原理、未试）
**几何约束的 2D mask 选择**：对查询视角的每张 2D mask，用候选的 3D 支撑打分——
把候选可见 Gaussian 投影到该视角，计算 mask 与其投影支撑的覆盖率/IoU，选“最符合 3D 支撑”的 mask，
文本相似度只作为先验。这样用几何身份而不是特征一致性来选 mask，直接针对 deep/recall 的 +0.16/+0.21。
潜在收益：即使只拿回一半，macro 约 +2。

## 3. 其他未被系统尝试的轴

1. **自适应 k / set cover**：released gap 常只选 1 个候选；oracle greedy5 0.75。用 mask 证据/覆盖做贪心加候选
   （加一个“覆盖新区域”的候选），目标是拿回 +7 的一部分。风险：过选会伤 found，需要覆盖增量准则。
2. **扩池 / 多视角 proposal**：recall 29 条池内最佳 0.027；greedy20 0.196。top-10 root 或跨视角 mask proposal
   可以新增候选；当前 query-view proposal 只救回 3 条（安全 +0.002）。
3. **场景校准**：ramen 0.609、figurines 0.613，远低于 teatime 0.822；oracle 分别是 0.690/0.792。
   per-scene 的分数分布/温度不同，global z 融合不是最优。
4. **mask 精修 / MWP**：所有增益都在“选集合”，没有改渲染掩膜质量。2D mask 可用于边界/孔洞 refinement，
   MWP 可删低贡献高斯；这两条是并列的质量轴，未测。
5. **跨数据集/多 seed**：全文结论仍只在 LERF 4 场景、单次运行。

## 4. 建议顺序

1. **几何约束 2D mask 选择**（新实验，最直接对应 +3.9 的 2D/3D 头寸）。
2. **自适应 k / set cover**（对应 +7.4 的联合头寸）。
3. **扩池/多视角 proposal**（对应 recall）。
4. **场景校准与 mask 精修**（稳定性和质量）。

## 5. 结论

没有到尽头。当前 0.676 距离：
- 2D/3D 族级 oracle 0.7145；
- 池内 oracle 0.7094；
- 贪心联合 0.7500。

最大的“没注意”是：**我们一直在 3D 池里换候选，却没有认真选 2D mask、也没有加第二个候选**。前者对 deep/recall 的上界高达 0.82/0.24，后者对应 +7 分。
