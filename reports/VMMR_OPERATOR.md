# 算子记录：视角模式最大读数（View-Mode Max Readout, VMMR）

版本：2026-11-04 · 代码分支 `research/mv-semantics`（`e06aa18`）
主指标：**场景等权宏平均**（每个场景先内平均，再对场景取平均）

---

## 0. 一句话

把每个 3D 区域的多个视角观测分解成 1–3 个视角模式，读取时用「最匹配的那个模式」代替「所有视角的平均」。
不改几何、不改候选搜索、不训练、不用 GT。

---

## 1. 动机

### 1.1 现象：一个区域只有一条向量，但它有很多张脸

ReLaGS 对每个区域 r 把 V 个视角的观测 `{x_v}`（单位向量）聚成一条：

```
keep_r = { v : mean_sim_v > mean(mean_sim) - 3*std(mean_sim) }     # ROFA
f_r    = normalize( Σ_{v∈keep_r} w_v · x_v )                       # w_v = visibility_portion
```

一个从正面、背面、被遮挡时都见过的区域，这些"脸"被压成一条**平均方向**。
当三个视角说它是椅子、两个视角说它是桌子时，平均向量两边都不像，对这两类查询都偏低。

### 1.2 实测：确实存在多模式，而且不是噪声

LERF ramen，244 个有观测的区域（8486 条观测，131 视角）：

| 量 | 值 |
|---|---|
| 单位化检查 | 全部 ‖x‖=1 |
| 区域内 resultant `R`（中位） | **0.897**（最小 0.822，最大 0.982） |
| 对应 vMF 集中度 `κ̂ = R(D-R²)/(1-R²)`（中位） | **2339**（min 1294 / max 13910） |
| **强制 K=2 时两中心余弦**（中位） | **0.843**（p25 0.785 / p75 0.891） |
| **强制 K=2 时少数派权重**（中位） | **0.35**（p75 0.42） |

即：观测很紧（R≈0.9），但**区域内确实有稳定的两簇结构**，少数派占三分之一。
现有读取只用了这条平均向量，等于对"多张脸"做了最保守的处理。

### 1.3 现有做法做了什么、没做什么

- **ROFA** 只剔除约 **1%** 的离群观测（实测保留率 98.1%–99.3%，各场景各层一致），
  剔除完仍然**取平均**。
- 已有工作（如 view-dependent semantics）指出了视角依赖问题，但解决方式多为**重编码/训练**。
- 本算子不碰特征侧：**只改读取这一步**。

## 2. 原理

### 2.1 视角模式分解

对区域 r 的观测 `{(x_v, w_v)}`，做加权球面 k-means：

```
min_{μ_k, a_v}  -Σ_v w_v (x_v · μ_{a_v})      s.t.  ‖μ_k‖ = 1,  a_v ∈ {1..K}
```

**K 不用标签选**。按视角分两折（视角奇偶），对每个候选 K 在训练折上拟合、
在留出折上算预测余弦：

```
score(K) = Σ_{held-out v} w_v · ( x_v · normalize(Σ_k γ_k μ_k) ) / Σ w_v
```

选 K 的规则（**预注册**）：

```
K* = 1
for K in 2..3:
    if score(K) > score(K*) + δ:   K* = K          δ = 2e-3（均值余弦）
```

δ 的作用：**噪声买不到分量**。3 个场景 × 2 层的实测 K 分布（vfM bank）：
K=1 占 10–65%，K=2 占 19–28%，K=3 占 12–65%——不是退化到 K=1，也不是全 K=3。

退化处理：观测 <4 → K=1；单视角 → K=1；含 NaN/零范数先剔除；空簇重播种到最差解释的观测。

### 2.2 读取：把"平均分"换成"最匹配模式的分"

记 `u(μ, q)` 为管线**原有**的区域–查询打分（LERF = 官方 canon 读数；ScanNet = `μ · t_q`）。
本算子只替换这一处：

```
s(r, q) = (1/β) · log Σ_k π_{r,k} · exp( β · u(μ_{r,k}, q) )        β = 10
```

- `β → 0`：退化为 `Σ_k π_k u(μ_k)`，即**对模式取平均**（这正是对照臂 `*_exp`）
- `β → ∞`：退化为 `max_k u(μ_k)`，即**问"这个区域有没有任何一个视角像它"**

**β 不是自由旋钮，是"平均 ↔ 最大"的插值系数**。取 β=10 因为与 canon 内部
`softmax(10·s)` 同刻度，且是运行前冻结的值。

### 2.3 为什么"取最大"对开集检索是对的

开集检索问的是"这个区域**能不能被这个短语指到**"。一个正面是杯子、背面看不到杯子的区域，
平均向量被稀释；取最大相当于问「**存在一个视角，它像这个短语吗**」。
平均回答的是"典型视角像不像"，问题不同。

**对闭集 argmax 则相反**：区域一次性判给一个类时，"取最匹配模式"会把区域推给
**任一子部分最像的类**（墙的一部分像地板，整块墙就成了地板）。这界定了作用域（见 §7）。

## 3. 实现

### 3.1 流水线位置

```
逐视角 2D 特征 ──投影(不变)──> 逐视角观测 {x_v, w_v} ──[本算子]──> 原型 bank ──[本算子]──> 区域分数
                                                          ↓
                                            其余一切不变：ROFA(可绕过)、候选搜索、gap 规则、渲染、IoU
```

### 3.2 三个组件

| 组件 | 文件 | 作用 |
|---|---|---|
| 观测导出 | `experiments/mv_semantics/export_frozen_observations.py` | 对**冻结 NAG** 直接投影，**不重聚类**；`--level` 任意层 |
| 契约校验 | `experiments/mv_semantics/obs_contract.py` | 用原 ROFA 公式重建 `nag_feat`，cos ≥0.995 才算观测可信 |
| 分解 + bank | `experiments/mv_semantics/kmeans_vmf.py`、`build_bank.py` | 加权球面 k-means（vMF-EM 作对照），留一视角选 K，导出 npz |
| 读数 | `experiments/mv_semantics/scorers.py`（LERF）、`deco/scannet/scan_mv_bank.py`（ScanNet） | 实现 §2.2 |
| 接入 | `eval_lerf_ovs.py` / `eval_scannet_3d.py` 的 `--mv-bank/--mv-mode/--mv-beta` | **默认关闭**；关闭时与改动前逐字节一致（已验证） |

### 3.3 关键实现细节

- **不重聚类**：观测是拿冻结 NAG 的 `labels[level]` 当区域划分投影出来的，所以
  **同一 NAG 的分数可以直接比较**；契约在 8 份 LERF + 10 份 ScanNet 导出上全部通过
  （LERF cos 0.9980–0.99996，ScanNet cos 0.99999）。
- **合约只信公式**：重建用生产的 `_filter_feature_outliers` 精确复算
  （`mean_sim > μ−3σ`、unbiased std、空集取 argmax）。观测数 ≤6 且重建 <0.9 时，
  做保留子集枚举（n≤3 时保留哪几条由 float32 末位差决定，属生产侧任意选择）。
- **bank 格式**：`{μ_k, π_k, κ_k}`（CSR 变长）+ `k / status / n_obs / n_views / sat_*`；
  无观测区域不写 bank，读数回退原分数。
- **刻度**：LERF 侧调用 `ClipSimMeasure.compute_similarity`（canon softmax，**不是裸余弦**），
  所以替换后的分数仍在 `[0,1]`、与 gap 规则同刻度；ScanNet 侧直接在点积空间合成。
- **确定性**：拟合 seed=0、6 次多起点；输入观测顺序打乱、视角 ID 置换后 bank 得分不变（单测覆盖）。
- **成本**：LERF 4 场景 8 层导出 ~25 min（GPU）；拟合 16 个 bank ~2 min（BLAS 单线程）；
  六臂评测 4 场景 ~20 min。ScanNet 10 场景导出 ~35 min，评测 ~15 min。

### 3.4 自检（22 项，全过）

退化样本数、单视角、全相同向量、近对径、NaN/零范数剔除、π 归一、μ 单位、
κ 有限、seed 决定性、观测顺序不变、`log C_D` 与 scipy 在 κ∈[2e2,5e4] 一致、
紧密区域不买分量；评测侧另验「关闭时逐字节等同」。

## 6. 消融实验

### 6.1 读数消融：平均 vs 取最大（同一批原型）

| 原型来源 | 平均读数 | 取最大读数 |
|---|---:|---:|
| k-means | 0.5696（−0.67） | 0.5759（−0.03） |
| vMF | 0.5813（+0.51） | **0.6115（+3.52）** |
| ScanNet K=19 | 0.3928（−1.06） | 0.4102（+0.68） |

**只有"取最大"在两个数据集上都不为负**；平均读数在两边都压在基线上。

### 6.2 区域消融：效应是否只来自多模式区域（核心）

按区域 K 值切 bank，其余不动（LERF）：

| 区域集 | 读数 | ramen | teatime | waldo | figurines | macro Δ |
|---|---|---:|---:|---:|---:|---:|
| 全域 | 取最大 | 0.4758 | 0.7054 | 0.5794 | 0.6853 | +3.52 |
| **仅 K≥2** | **取最大** | 0.4758 | 0.7054 | 0.5794 | 0.6853 | **+3.52** |
| 仅 K≥2 | 平均 | 0.4936 | 0.6993 | 0.5681 | 0.5811 | +0.93 |
| 仅 K=1 | 取最大≡平均 | 0.4936 | 0.6931 | 0.5202 | 0.5811 | −0.42 |

三条结论：
1. **K≥2 子集逐场景复现全域结果（四位小数全部相同）** ⇒ 增益 100% 来自多模式区域。
2. **仅 K=1 ≈ 基线** ⇒ "换个原型"本身无用。
3. **K≥2 + 平均只有 +0.93（CI 含 0）** ⇒ "多模式"与"取最大"缺一不可。

ScanNet 上该结构一致（K≥2 +0.68 / K=1 −0.00），说明**归因稳定**。

### 6.3 β 扫描（"平均↔最大"的插值位置）

LERF（场景等权 Δ）：

| β | 5 | 10 | 20 | 50 |
|---|---:|---:|---:|---:|
| `vmf_lse` | −0.14 | **+3.52** | +3.64 | +0.81 |
| `km_lse` | −1.36 | −0.03 | −0.97 | −0.64 |

ScanNet K=19：β=1 −0.22 / 5 +0.56 / **10 +0.68** / 20 +0.48 / 50 −2.12。

β 在两个数据集上的**最优位置不同**（LERF 10–20，ScanNet 10），且过大都变差——
这支持"取最大"的直觉，也说明 β 必须固定而非常数调优。

### 6.4 独立底座复现

figurines 换一次**独立重建**（L3 175 vs 176 区，L2 特征 cos 0.905）：

| 臂 | 原底座 | 独立重建 |
|---|---:|---:|
| baseline | 0.5811 | 0.5811 |
| `km_exp` / `vmf_exp` | 0.5811 | 0.5811 |
| **`vmf_lse`** | 0.6853 | **0.6962** |

效应不是某一次重建的伪影。

### 6.5 vMF 是否需要（已证伪的一条）

16 个 bank 的 vMF 责任度：`sat_median` 全为 **1.000**，`sat_hard ≥ 0.997`。
κ≈10³、D=512 时 `exp(κ·Δcos)` 完全饱和 ⇒ **full-vMF ≡ 硬球面 k-means**，
"软混合"只是名义。因此方法里只有 k-means；vMF 仅作对照臂。

### 6.6 为什么不能挂在官方 NAG 上（数据集边界）

released `sai_nag.pt`（0.6401 所用）的 `labels[0]` **不等于**模型目录的 `nag-l1.pt`，
观测重建 cos 只有 **0.939**（15/248 区 <0.9）。它是另一套 level-0 划分，
观测级方法无法锚定；本轮全部结果因此建立在重建底座（0.5762）上。

### 6.7 口径敏感性（诊断，不作为判据）

主指标为场景等权宏平均。另附一种聚合供参考：把 10 个 ScanNet 场景的预测合起来按类支持度加权
（池化），K=19 为 **−1.00**（5 类改善 / 9 类退化，sofa −18.4pp、door −6.1pp）；
LERF 按查询池化为 **+3.07** [+0.48,+5.81]。
LERF 在两种聚合下都为正，ScanNet 只在场景等权下为正——使用该算子时需注意此差异。

### 6.8 参数汇总

| 参数 | 取值 | 敏感性 |
|---|---|---|
| K 上限 | 3 | K 分布 10–65% / 19–28% / 12–65%（K=1/2/3） |
| K 选择 margin δ | 2e-3 | 预注册；紧密区域不买分量（单测） |
| β | 10 | §6.3；LERF 最优 10–20、ScanNet 10，过大变差 |
| 拟合 | 加权球面 k-means，6 起点，seed=0 | vMF-EM 等价（§6.5） |
| 覆盖层 | LERF 用 labels level 2+3；ScanNet 用最粗层 | 仅这两层被候选搜索读取 |

## 7. 作用域与使用建议

| 场景 | 结论 | 依据 |
|---|---|---|
| **LERF-OVS 单查询开集检索** | **有效** | 场景等权 +3.52 [+0.64,+7.03]；LOSO +2.59；查询池化 +3.07；消融归因干净；独立底座复现 |
| ScanNet 闭集 argmax | 增益微弱且不稳 | 场景等权 K=19 +0.68 [CI 含 0]；K=15/10 为负；β=50 翻号 |

**机理**：开集检索问"是否存在一个视角像该短语"——取最大是正确问题；
闭集 argmax 把区域判给一个类——取最大会把区域推给任一子部分最像的类。
**建议只在单查询检索类任务上使用，闭集多类判决需要另一套读数。**

## 9. 与既有工作的关系

- **Cen et al. (ICML 2025)** 指出 3D-LGS 的视角依赖语义；本算子的差别是**不训练、不重编码**，
  只在读取端把"平均"换成"最匹配模式"，并给出"效应只存在于多模式区域"的消融。
- **ReLaGS 的 ROFA** 剔除约 1% 异常观测后仍取平均；本算子保留全部观测，将其组织为若干模式。
- **同轴已有方法**：本仓库的候选审计器（+3.13，官方底座）与本算子在同一判决轴上；
  两者是否互补**尚未测**，若要在论文中并列，需补组合实验。
### 6.9 变体：先用 ROFA 去掉不稳定观测，再做模式分解（2026-11-04 追加）

原实现的模式分解用**全部观测**（不做预筛），而生产 `nag_feat` 是 ROFA 之后的产物。
把 ROFA 提前到分解之前（同一公式：`mean_sim > μ−3σ`，n≤3 时保持原样），其余不变：

| 场景 | baseline | 取最大（全观测） | **取最大（ROFA 预筛）** |
|---|---:|---:|---:|

建议把"ROFA 预筛 + 取最大读数"作为默认组合。

### 10.6 为什么这么差：审计

**先排除实现错误（四项独立检查全部通过）**

| 检查 | 结果 |
|---|---|
| 基线复现 | ramen **0.5099** / teatime **0.8149** / waldo **0.6025**，与 `LERF_OVS_AUTONOMOUS_BASE.md` 的 50.99/81.49/60.25 逐位一致 |
| 观测契约 | ramen 0.99973/0.99966、teatime 0.99946/0.99929、waldo 通过，0 区 <0.9 |
| K=1 子集 | **0.5099，逐位等于基线** ⇒ bank 与 NAG 的对齐无误 |
| K≥2 子集 | **0.4656，等于全部损失** ⇒ 归因定位正确 |

**机制：这是一个"覆盖度先验"，不是语义判别器**

逐查询测量 arm 相对基线的分数变化（ramen，64.71 底座）：

| 量 | 值 |
|---|---|
| 平均偏移 | L1 +0.004~+0.006；L2 +0.004~+0.007 |
| 按模式数 | K=1 +0.000~+0.004；K=2 +0.004~+0.007；**K=3 +0.007~+0.011** |
| corr(Δscore, 观测视角数) | **+0.41**（"coffee mug"） |
| corr(Δscore, 区域高斯数) | +0.09 / −0.04（弱） |

即 `LSE(β)=max_k u_k + log-sum 奖励` 让**被越多视角看到、模式越多的区域得分越高**——
与被看到的内容无关。它在效果上是一个可见性/覆盖度先验。

**后果：掩膜尺寸被推离标定**

| 场景 | baseline pred/gt | `vmf_lse` pred/gt | IoU |
|---|---:|---:|---:|
| ramen | **1.25**（已标定） | **5.19** | 0.5099 → 0.4240 |
| teatime | 1.41 | 1.38 | 0.8149 → 0.7617 |

候选数几乎不变（2.24→2.28），所以不是"选得更多"，而是**选中的候选更大**。
注意：teatime 的 pred/gt 几乎没变（1.41→1.38）却仍掉 5.3pp，说明**尺寸效应只解释 ramen**；
在 teatime/waldo 上是**换成了别的候选**（选错），不是尺寸。两种失效同时存在。

**这解释了符号翻转**

| 底座 | baseline pred/gt | 算子把尺寸推向 | IoU |
|---|---:|---|---|
| 0.5762（弱） | **5.90**（严重过分割） | 4.99（更接近 GT） | **+5.07** |
| 64.71（作者口径） | **1.25**（已标定） | 5.19（远离 GT） | **−4~−9** |

同一个"把区域推向更被覆盖的候选"的效应，在**过分割的底座上像补药，在已标定的底座上是毒药**。
之前的 +5.07 因此主要是尺寸标定效应，不是语义匹配的改进。

**结论**：这不是实现 bug，是**算子本身的失效模式**——它没有对齐"语义正确性"，
而是对齐了"这个区域被看得多不多"。在基线尺寸已经正确的语义场上，这种对齐是有害的。

## 11. RVMA：簇内 ROFA（2026-11-05）

### 11.1 定义

在 `rofa_vmmr`（区域级 ROFA → 拟合 → canon LSE）之上，**拟合之后再对每个模式内部做一次 ROFA**：

```
区域级 ROFA（τ=3） → 加权球面 k-means / vMF-EM（K∈{1,2,3}）
   → 对每个模式 k：取其成员观测 X_k，再做一次 rofa_keep(X_k, w_k, τ=3)
   → μ_k = normalize(Σ_{i∈keep_k} w_i x_i)，π_k = Σ_{i∈keep_k} w_i / Σ
   → canon LSE(β=10)
```

单模式区域（K=1）跳过第二次过滤，避免对同一集合重复施加 ROFA。K 不变，只有 μ/π 变。

### 11.2 结果（0.5762 重建底座，场景等权）

| 臂 | ramen | teatime | waldo | figurines | 宏平均 |
|---|---:|---:|---:|---:|---:|
| baseline | 0.4936 | 0.6931 | 0.5372 | 0.5811 | 0.5762 |
| vmmr_unfiltered | 0.4758 | 0.7054 | 0.5794 | 0.6853 | 0.6115 |
| rofa_vmmr（区域级） | 0.4758 | 0.7054 | 0.6151 | 0.7114 | **0.6269** |
| **RVMA（簇内）** | 0.4758 | 0.7054 | 0.6151 | **0.7110** | **0.6268** |

**逐查询对比 rofa_vmmr：208 条里只有 3 条变化，全在 figurines 的 `old camera`**
（−4.52 / +1.61 / +0.30 pp），净 −0.04pp。

### 11.3 为什么几乎不动

原型其实**动了**：

| 场景 | 层 | 原型数 | 被改动的原型 | 最小余弦 | π 最大变化 |
|---|---|---:|---:|---:|---:|
| ramen | L3 / L2 | 439 / 920 | 35 / 80 | 0.893 / 0.742 | 0.15 / 0.14 |
| teatime | L3 / L2 | 1900 / 3821 | 58 / 110 | 0.737 / 0.693 | 0.16 / 0.21 |
| waldo | L3 / L2 | 737 / 1745 | 30 / 73 | 0.759 / 0.655 | 0.17 / 0.13 |
| figurines | L3 / L2 | 444 / 1144 | 70 / 157 | 0.823 / 0.915 | 0.11 / 0.09 |

K 一个都没变。但 **LSE(β=10) 的读数对这些幅度不敏感**：分数变化小于候选间的 gap，
选择集不变。也就是说，区域级 ROFA 已经把"不稳定视角"清掉了，簇内再清一遍没有新增信息。

**结论：RVMA 已实现并可复现，但在该底座上相对 rofa_vmmr 是 0（−0.01pp），不构成新的增益。**
