# 实验文档：冻结开放词汇 3D 场上的判决审计（LERF-OVS + ScanNet-10）

日期：2026-11-02
范围：只覆盖 LERF-OVS 与 ScanNet-10 两个数据集（3D-OVS 暂停，见 §5.4）。
所有数字均注明口径；方法 training-free、不使用 GT、不做逐数据集调参。

---

## 摘要

开放词汇 3D 分割通常被表述为"把语义场建得更好"。我们换一个提法：**给定一个冻结的场，
它已经对查询做出了选择（released decision）；我们能否在不重训、不用 GT 的前提下，判断这个
承诺该不该被改判？** 我们把该问题形式化为**判决审计**：released 选择是"现任"，逐视角 2D
掩膜的文本判定是"证人"；挑战者只有在**同一批证人上配对占优**时才获得改判许可（
半样本多数证书），另外用**范围支配**修正文本相似度的尺度盲区。在 LERF-OVS 官方锚点上，
审计器把 macro mIoU 从 64.01 提到 **67.11（+3.13，配对 CI [+1.14,+5.48]）**，改判集中在
场排得深的查询（24%）而几乎不动 found（2.3%）；常数在第二个冻结场（center=image，63.93）
上不变仍 +2.99，剔除查询视角仍 +2.77。在 ScanNet-10 上我们报告**负结果**：闭集的根级判决
审计（50.18→45.91）、同 query 重构后的集合审计（50.18→49.26）、以及独立 SAM 证人
（保守证书弃权、激进证书 −14.6）都失败，原因是根是"区域"而非"物体"、且证人优势与 mask IoU
不对齐。由此给出方法的三个前提：同 query、证人度量与指标对齐、场粒度足够。另外我们对 ScanNet 上
"逐类标准化 + 视角中心化"的 +8.80 做了归因：场景级只有逐类标准化 **+5.62** 通过显著性检验；
视角中心化相对未中心化证据的独立增益为 **+0.39（CI [−0.03,+0.82]）**，因此它不构成一条可主张的方法线。

## 1. 引言

### 1.1 观察

在 released 语义场（ReLaGS/DeCo 的 NAG）上，失败不在于"场里没有证据"，而在于"选择"
（手头另一份诊断：2D 逐视角 rank1 命中 77.4%，3D 最佳候选 IoU 0.708，但选择只有 0.64；
单候选池 oracle 0.7094）。三个可测的失败模式：

- **M1 尺度盲**：文本相似度对尺度不敏感，小碎片可以先于整体胜出（deep 族 0.2914）；
- **M2 聚合抹平分歧**：合并后的特征给出"自信"分数，哪怕各视角互相矛盾（一致性 found 13.7–15.3%，
  而逐视角 top-3 证据 65.3%）；
- **M3 前缀不稳定**：released 前缀由分数 gap 决定，gap 只度量分数间隔，不度量决策稳定性。

### 1.2 贡献

1. **问题重述**：把冻结场上的开放词汇分割重述为"判决审计"，并给出对应的三条可测失败模式。
2. **机制**：配对证人证书（视角难度在做差时抵消，不估计视角可靠性）+ 范围支配（修正尺度盲）。
3. **LERF-OVS**：training-free、零拟合，64.01 → 67.11（+3.13，CI 下界 +1.14），并通过跨场、
   leave-query-view-out、阈值敏感性三项检查。
4. **ScanNet-10 负结果与作用域**：三种审计形态均失败，明确指出方法的前提（同 query、
   证人-指标对齐、实例粒度），并与"全局校准"（C1+C2，40.36→50.18）区分层次。

## 2. 方法

### 2.1 定义

对查询 $t$，候选 $c$ 在视角 $v$ 的**证词**：$a_v(c)=\langle \phi_v(M_{v,c}), t\rangle$
（该视角用候选的 2D 掩膜取到的区域特征与文本的相似度）。选择 $S$ 在视角 $v$ 的**支持度**：
$E_v(S)=\max_{c\in S} a_v(c)$（一个视角通过它最看得上的成员支持一个选择）。
挑战者 $B$ 相对现任 $A$ 的**配对优势**：$\delta_v = E_v(B)-E_v(A)$。

### 2.2 证书（半样本多数）

从两侧都可见的视角中随机取一半，重复 300 次；若 $\overline{\delta}>0$ 的比例 ≥ 1/2，
则 $B$ 获得改判许可。**没有幅度阈值，只有稳定性**；置信水平 π 只影响触发频率。

### 2.3 范围支配

若现任 top 候选面积 < 0.1% 且存在候选面积 > 2× 现任，则把
$z(\text{area})+z(\text{mean\_vis})$ 最大的挑战者并入现任（训练-free 的尺度修正）。

### 2.4 仲裁

默认 = 范围并入后的 release；挑战者 = `z(NAG)+1.0·z(证据)` 的重排（与 LERF 的 mask rerank
一致）；若证书通过则改用挑战者，否则保留默认。

### 2.5 前提（由实验得到）

- **P1 同一 query**：现任与挑战者必须是同一个问题的两个答案（同一文本、不同候选集）；
- **P2 证人-指标对齐**：配对优势必须与任务指标（mask IoU）相关；
- **P3 场粒度**：候选要足够细（LERF 的叶级超点；ScanNet 的根级区域不满足）。

### 3.5.1 C1/C2 的条件性（特征侧 vs 文本侧）

| 数据集 / 协议 | 配置 | macro mIoU | 变化 |
|---|---|---:|---:|
| LERF-OVS 官方锚点 | canon（center=none） | **0.6401** | — |
| LERF-OVS 官方锚点 | **template + LSE**（同一评测器/场） | 0.6003 | **−3.98**（teatime 0.810→0.691） |
| LERF-OVS 官方锚点 | center=image（C1）canon | 0.6393 | −0.08 |
| 3D-OVS 复现协议 | canon → template | 0.564 → 0.493 | −7.1 |
| ScanNet-10 认证 | off → **C1+C2** | 0.4036 → **0.5018** | **+9.8**（C2 与 C1 未拆） |

观察：**C2（模板库 + LSE）是固定词表设备**。ScanNet 的类名是 19 个固定名词，模板带来增益；
LERF-OVS 的查询是自由短语（"old camera"、"green apple"…），模板反而破坏对齐（−3.98）；
3D-OVS 同样为负。C1（特征中心化）在 LERF 上中性（−0.08），在 ScanNet 上与 C2 合并产生 +9.8。
**缺口**：ScanNet 上没有 C2-only 臂（C1/C2 合并），C2 在 ScanNet 的单独贡献尚未受控。

对审计的含义（本轮实测）：把 C1 施于**证人特征**（逐视角去均值）并不能救 ScanNet 审计——
同 query 审计 0.4926 → 0.4615（更差），多数证书 0.4666 → 0.4395。C1 去掉的是承载跨类校准的
共享成分，反而让配对差分更噪；审计的失败在实例粒度与证人-指标对齐，不在校准层。

### 3.4.2 查询时校准：逐类标准化 + 视角中心化（ScanNet-10，锚点 = ReLaGS 场）

方法：逐 root 逐类 z-score 标准化（query-agnostic、无 GT）+ 逐视角证据
（root 在视角 v 的相似度取 top-3 均值；视角中心化版本为 s'_v = s_v − α·mean_{view v} s_v，
α=0.5）+ 以 β=0.5 与标准化分数融合。

**命名更正**：该操作是对**相似度**做视角均值去偏，不是特征空间的局部缩放，统一称
**视角中心化（view centering, VC）**；早前记作 VCLS（View-Wise Similarity Centering）。
代数上，当视角均值与查询无关时，它就是逐视角的特征中心化，**不改变同一视角内的候选排序**
（LERF 上已实测：within-view 文本排名 improve/same/worse = 3/48/5、11/52/8、8/50/1、1/19/2，
top1 IoU 变化 <0.006，见 `LERF_2D3D_FEATURE_DIAGNOSTICS.md` §3）。因此它只能改变
**跨视角聚合后的分数**，这一点决定了下面的归因必须控制"是否真的需要视角轴"。

### 3.4.2.1 归因：+8.80 里有多少来自视角轴？

在同一个 10 场景、同一份 field、α=0.5、β=0.5、top-3 证据、argmax 逐 root 赋类的口径下，
一次跑完下列 9 个变体（`scannet_calib_ablation.py`，产物
`calib_ablation_20261103/<scene>.log`）：

- `raw` released；`zR` 逐类标准化；
- `E0` 证据（**不做任何中心化**）、`Ev` 证据（逐视角中心化）、`Es` 证据（场景中心化）；
- `R+bzEv` 只融合不标准化；`zR+bzE0` / `zR+bzEv` / `zR+bzEs` 标准化 + 融合。

（如 `zR+E0 − zR` 配对均值 +2.80 vs macro 差 +2.79；`zR+Ev − zR+Es` +0.81 vs +0.80）。

**判据（预先设定）**：控制 zR、β 与融合之后，若 `Ev` 稳定优于 `Es` 和 `E0`，则视角轴携带独立信息；
否则按预设判据降级为消融项（**只下调主张等级，不对机制下判断**）。

**判定（两条，强度不同，必须分开写）**

**（一）成立：视角中心化没有稳定的独立增益。**
`zR+Ev − zR+E0 = +0.39`，CI [−0.03, +0.82]。两支高度相关，所以配对差分的 CI 很窄——这条
不只是"不显著"，而是一个**上界**：独立增益不太可能超过 ~0.8 pp。
同理 `zR+Ev − zR+Es = +0.80`（配对均值 +0.81，CI [+0.00, +1.82]）。

**（二）不成立（本实验无法回答）："视角信息被 zR 吸收"。**
融合后的增量从证据单用时的 +4.28 降到 +0.39，只能说明**在这套融合规则下**视角项对最终判决
贡献很小。可能的原因至少四种：两支分数相关、逐类标准化的尺度效应、β=0.5 的权重、两支的
预测错误高度重合。要判定"吸收"，必须对融合权重与相关结构做受控实验（例如 β 扫描 + 残差
相关性分解），**本轮没有做**。因此文档中不使用"被吸收/淹没"这一表述。

**关于 +2.79 与分解比例（更正）**
`zR+E0 − zR = +2.79`（48.77 − 45.98；逐场景配对均值为 +2.80，两者差 0.01，来自日志按 2 位小数
存储），其 CI 为 **[−0.82, +6.86]，同样跨零**，**不能称为统计显著**。因此：

- "64% / 32% / 4%"只是**点估计的加减分解**，不是方差分解，也不表示 32% 那一项已经确立；
- 唯一有统计支撑的是 **+5.62（9/10 场景胜，CI [+2.86, +8.40]）**；
- 证据融合项（+2.79 ~ +3.18）在 n=10 的场景级检验下都跨零，只能作为**方向性观察**。

**证据单用时视角项确实有效（该口径下）**
`Ev − E0 = +4.28`（CI [+1.44, +7.16]，8/10）、`Ev − Es = +2.75`（CI [+0.41, +5.12]，7/10）。
这说明视角中心化改善了**证据估计本身**；它为什么没有等量地传导到最终判决，是上面（二）留下的
未解问题，不能反过来当作"信息已被吸收"的证据。

**结论与处置**：视角中心化**不构成一条可主张的方法线**，只能作为"逐类标准化 + 证据融合"这一层的
消融/工程组件，**不得作为 ScanNet 的 headline 数字**。也**不要**以"信息被 zR 吸收"为由去改造它——
那个机制未经验证；正确的表述是"在现有融合规则下，它没有可检出（< ~0.8 pp）的独立贡献"。

**口径瑕疵（如实标注）**：`evidence()` 对无观测 root 填 0，使 `Es` 的逐类 z-score 与 `E0` 不完全
等价，`Es` 不是干净的"去掉视角轴"控制变量；但主判据 `zR+Ev − zR+E0` 不依赖 `Es`，结论不受影响。

**已校准的 C1+C2 场**：同一流程 +0.77（CI 跨零），且在 0062（82.5）上退化。结合上面的归因，
点估计上该增益主要来自逐类标准化，因此"适用条件是未校准场"的正确解读是：**标准化在未校准场上
有空间可拿，视角中心化在两种场上都没有可检出的独立贡献**。

### 3.4.3 局部对比语义（B0–B6，ScanNet-10 + LERF-OVS）

动机：让区域的语义不仅反映"它像什么"，还反映"它比周围干扰区域更不像什么"。保持候选、
CLIP 特征、视角、层级、融合规则全部不变，**只替换逐视角证据的计算方式**。

| 变体 | 逐视角证据 |
|---|---|
| E0 | `s_v(c,t)`，不加对比 |
| VC | `s_v − α·mean_view s_v`（全局视角偏移，即前面的视角中心化） |
| Erand | `s_v − mean_{n∈随机 K} s_v(n)`，与 Eknn 同 K 同权重 |
| Eknn | `s_v − mean_{n∈空间 kNN(c)∩可见(v)} s_v(n)` |
| Ehard | `s_v − τ·logmeanexp_{kNN}`，τ = γ·sd(S) 固定，不调 |
| Epair | `z(top-k 证据) + η·z(mean_n med_v δ_v·(2q_n−1))`，**保留绝对项** |

共同约束：参考区域必须与候选**在同一视角共同可见**，否则该视角退回不对比并计入 coverage；
top-3 视角聚合、逐类 zR、β=0.5 全部固定。Epair 的绝对锚点是刻意的——纯相对统计只回答
"c 是否胜过邻居"，不回答"c 像不像 t"。

**结论：按预设停止条件停止，不进入三维局部关系表示。**

1. **两个数据集、两种粒度上，所有邻域对比都低于不加对比。** ScanNet 最温和的 Ehard 也低
   2.58；LERF 上 Eknn/Ehard 显著低 4.3 分。
2. **不是"局部"在起作用。** 随机参考（−2.96 / −1.09）与空间 kNN（−2.89 / −4.31）同一量级，
   ScanNet 上几乎相同。说明损害来自"减掉一个参考均值"本身，而不是参考集合的几何或语义关系。
3. **损害方式可解释。** 对比把"这个区域有多像 X"改写成"它比邻居更像 X 多少"，等于用相对
   显著性替代绝对语义；而两个数据集的读端都是**绝对类别/候选选择**。root 选择准确率同步下降
   （37.03 → 34.01）也支持这一点。
4. **Epair 的 −11.84 是设计缺陷，不是机制否定。** 最初版本没有绝对项，纯粹是相对统计；改成
   `z(base) + η·z(pair)` 后 ScanNet 仍低但量级收窄，LERF 上回到 −0.65 且不显著。这只能说明
   "成对跨视角统计"在当前读端下无法单独充当证据，**不能**据此否定跨视角一致性这个机制。

**口径限制（必须与结论一起报告）**

- **层级方向是反的**：两个数据集的 NAG 都是 level 3 最粗、level 0 最细，root 是最粗层。
  因此"同父节点的兄弟区域"在两处都不存在，B4 直接不适用（`sib_deg = 0`，10/10 场景）。
- **LERF 的证据只到 level-3**：候选里约 2.5 个是 level-2、3.3 个是 level-3，而观测只在
  level-3 上导出，同一 root 下的不同 level-2 候选共享同一份证据。所以 LERF 这轮**不是**叶级
  局部对比的干净检验，而是"region 级"检验。
- **层级与几何邻域在 ScanNet 上是同一物体的不同部分**，这正好复现了 §3.4 的粒度问题。

由此，这个方向若要继续，前提是**先有叶级观测**（level 0/1 的逐视角特征导出）；在现有
level-3 观测上，任何邻域对比都只能测到"粗区域之间"，测不到"物体部件之间"。

### 3.5 与学习型 module C 的区别

早期 0.6760 的 module C 使用冻结 LOSO IoU 回归器（preds.csv 的 `pred` 是**预测 IoU**），
属于学习组件；本方法的 0.6711 完全 training-free。两者数字接近，但协议等级不同，
0.6760 只能作为"学习选择层"的消融。

## 6. 下一步：二维—三维语义映射的可辨识性（唯一决定性实验）

### 6.1 由本轮结果得到的判断

本轮**否定了一个假设**：*视角均值偏移是当前三维开放词汇分割的主要性能瓶颈*。至少在这套
ScanNet 实验与现有融合规则下，证据不支持该判断。因此不再沿 VCLS → 三维对应去偏 → 联合优化
求解器的路线推进。不能因为 Splat Feature Solver 通过数学建模成功，就把一个收益有限的校正
操作改写成逆问题。

同时必须明确：下面两个现象**目前没有建立因果联系**，不能宣称它们共同证明了某种"三维信息损失
机制"：

1. 未中心化的多视角证据 E0 与 zR 融合后点估计 +2.79~+3.18（方向为正，CI 跨零，未确立）；
2. LERF-OVS 上部分细粒度目标根本不在 released 候选区域内——即使语义评分正确，也无法恢复边界
   （这是 ceiling 问题，不是排序问题）。

它们共同的候选解释是"二维→三维映射与聚合过程中丢失了细粒度可分性"，但这仍是假设，需要下一节
的实验来检验。

### 6.2 实验设计

固定原始图像、相机与 Gaussian 几何，对同一组困难查询（LERF 的 deep/recall 族 + ScanNet 的小
物体根），在四个阶段分别测量同一件事：**目标是否还可被区分**。

| 阶段 | 诊断量 | 想回答的问题 |
|---|---|---|
| S1 原始二维视觉区域 | 目标多边形内外的文本相似度 gap（同图、同编码器） | 二维观测里**是否本来就有**可分的细粒度证据 |
| S2 二维→Gaussian 映射后 | 同一批像素所对应 Gaussian 子集的同口径 gap | 映射这一环**丢了多少**可分性 |
| S3 ROFA 聚合与层级合并后 | 合并簇特征上的同口径 gap，逐层（L0/L1/L2/L3） | 哪一层**开始**不可分 |
| S4 最终候选集合 | GT Gaussian 落在 released 候选内的**召回上限** | 还剩多少**理论恢复空间** |

关键约束：

- S1 必须是**同一文本编码器、同一提示、同图内相对 gap**，否则无法与 S2–S4 相减；
- S1→S2→S3 的 gap 必须逐样本配对（同一目标、同一 query），否则差值会被目标难度掩盖；
- S4 的召回上限是**headroom 量**，只用 GT 做诊断，不进入方法；
- 需要同时记录查询数，deep/recall 族样本稀少（LERF 上仅 25/30 条），结论要按族报告。

### 6.3 判定标准（先定后跑）

- **若成立**：细粒度目标在 S1 可区分（gap 明显 >0 且与难易相关），但在 S2 或 S3 系统性塌缩
  （gap 显著下降、且下降幅度在"本来可分"的目标上更大）→ 这就是一个可复现的基础问题，
  可以围绕它提出新的三维语义表示或求解方法。
- **若不成立**（S1 本身就不可分，或 S3→S4 才是主要损失）→ 说明瓶颈不在映射环节，
  应继续寻找其他基础问题，**不要**退回到几十轮局部调参。

与 Splat Feature Solver 的区别：后者研究"给定二维观测后如何高效、稳定地求解特征"；本节研究
"观测本身的可辨识性，以及它能否在对细粒度三维语义区域恢复时被保留"。

### 6.4 由局部对比实验得到的前置条件

§3.4.3 的负结果不只是"这个变体不行"，它同时给出了一个可执行的前置条件：**S3（聚合层）
必须在叶级测量**。现有两个数据集的逐视角观测都只导出到最粗层（ScanNet 380 个 root、
LERF 177 个 level-3 区域），候选在 level-2/3 上混合、同一 root 的多个候选共享一份证据。
在这样的观测上，任何"区域之间"的对比都测不到"物体部件之间"的可分性变化。

因此 S1–S4 之前应增加一步 **S0：导出 level 0/1 的逐视角特征观测**，并验证其覆盖率。
如果这一步做不到（例如 SAM 掩膜数量上限），那么 §6 的第一个问题应该改为"可辨识性损失
发生在观测生成本身，还是在观测之后"，而不是继续在聚合层做对比。

### 6.5 与 VCLS 的关系

本轮归因只回答"逐视角中心化该不该做"，不回答"视角信息为什么没传导到判决"（§3.4.2.1 判定二）。
后者作为**开放问题**记录在此，**不在 VCLS 名下追加实验**；若 S1–S4 中 S2/S3 出现塌缩，它自然会
给出该问题的答案形式（可分性在映射层就没了，与融合规则无关）。
