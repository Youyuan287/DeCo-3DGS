# 边界损失：ReLaGS 2D-3D-2D 中被忽视的关键难点

日期：2026-11-01
结论：**边界/掩膜保真度是一个独立于“身份/候选”的瓶颈；即使 GT 最好的 2D mask，
BIoU 也远不到 95%，经过 2D→3D→2D 后进一步下降。**

> 2026-11-01 补注：**像素 BIoU 只是评测探针，方法空间应是边界高斯；但“边界高斯 +
> 多峰分布 + late-argmax”已是 DIGS 的核心贡献（LERF-OVS 71.95）。**
> 本文的 BIoU 数字用于诊断 2D→3D→2D 的掩膜损失，不能作为新方法主张。
> 高斯级头寸与 DIGS 之后的空位见 `reports/GAUSSIAN_HEADROOM_AND_DIGS_POSITIONING.md`。

---

## 1. ReLaGS 的 2D-3D-2D 到底做了什么

### 1.1 2D → 3D（merge_proj）

- 每个视角渲染 `weight`，取 `seg_map[level]` 的 SAM mask 标签与 mask 特征；
- 对每个 superpoint，计算它落在各 mask 内的比例 `ratio`；
- `RATIO_THRESHOLD = 0.3`：比例低于 0.3 的 mask 贡献被丢弃；
- `sp_feat = sp_mask_mat @ view_level_feature`：**一个 superpoint 的逐视角特征是多张 mask 特征的加权混合**；
- 用可见性比例累积多视角特征；ROFA 去 outlier 后平均；
- 层级区域生长（`thres_connect 0.9,0.7,0.7`、`thres_merge 20`）把相邻 superpoint 合并成更大区域。

**边界在哪里丢的**：
1. **mask 特征是整张 mask 的池化向量**，没有边界/距离信息；
2. ratio < 0.3 的 mask 被丢弃 → **部分覆盖的薄结构、边界区域直接消失**；
3. superpoint 是几何/图划分的结果，边界不一定和 mask 边界对齐；
4. 多张 mask 加权混合 → 物体边界上的 superpoint 会混入邻居/背景语义；
5. 区域生长按特征相似度合并，边界会被进一步“抹平”。

### 1.2 3D → 2D（推理渲染）

- 文本打分选中区域后，把该区域的 Gaussian 语义设为 1，渲染 `semantics > 0.5`；
- 预测边界由 **Gaussian splat 的覆盖/不透明度/尺度**决定，而不是原始 2D mask 边界；
- Gaussian 是各向异性椭圆，边界会膨胀/收缩；薄结构、孔洞、细边界容易丢；
- 没有使用任何 2D mask 的边界先验做约束。

**结论**：ReLaGS 的 2D-3D-2D 是一个**语义+几何的双重有损过程**：
- 语义损失：mask 特征混合/ROFA 选共享语义；
- mask/边界损失：ratio 阈值、superpoint 边界、Gaussian splat 边界。

## 2. 用 GT 量化边界上限（Boundary IoU）

定义：`B(mask)` = 距 mask 边界 d 像素内的 band；`BIoU = |B(pred)∩B(gt)| / |B(pred)∪B(gt)|`。
d = 2% 和 1% 图像对角线，两种带宽。

### 2.1 按 IoU 选出的 2D mask

对每条查询，在查询视角的 level-3 SAM mask 中，**按与 GT 的面积 IoU 选一张**，
再对这张 mask 算 BIoU。所以 0.678 是“面积 IoU 最好的那张 mask 的 BIoU”，
不是“所有 mask 中 BIoU 最高的那张”。

| 选 mask 的准则 | 2D IoU | 2D BIoU 2% | 2D BIoU 1% | BIoU≥0.95 (2%) |
|---|---:|---:|---:|---:|
| 面积 IoU 最好 | 0.635 | **0.678** | 0.633 | 41.8% |
| BIoU 2% 最好（oracle） | 0.620 | **0.694** | — | 41.8% |
| BIoU 1% 最好（oracle） | — | — | **0.645** | 21.6% |

按 BIoU 重新选 mask，只把 2% 均值从 0.678 抬到 0.694（中位数 0.870→0.881），
只有 11.5% 的查询提升超过 0.01。**所以 0.678 不是选择准则造成的测量偏差。**

### 2.2 0.678 是均值，不是“典型的最好 mask”

| 统计量 | 2D IoU | 2D BIoU 2% | 2D BIoU 1% |
|---|---:|---:|---:|
| mean | 0.635 | 0.678 | 0.633 |
| median | 0.833 | **0.870** | 0.787 |
| 25% 分位 | 0.246 | 0.399 | 0.361 |
| 10% 分位 | 0.021 | 0.102 | 0.100 |
| ≥0.95 | 31.7% | 41.8% | 21.6% |

均值被左尾拖低：一半查询的 2D BIoU 已经 ≥0.87，但 10% 的查询只有 0.10。
**“最好的 mask 只有 0.678”是均值表述；典型查询（中位数）是 0.87，不是 0.678。**

另外一个容易误读的点：2% band 下 BIoU 均值（0.678）**高于**面积 IoU（0.635），
不是边界指标更宽松，而是两者度量不同：SAM 的 GT-best mask 常偏保守/内缩，
2% band（512 图约 14 px）会覆盖内缩边界；到 1% band（约 7 px）就降到 0.633。
边界误差 10 px 时，面积 IoU 仍有 0.90，但 2% BIoU 只有约 0.71——这正是 BIoU 要暴露的。

### 2.3 分族：0.678 是两类查询的混合

| 族 | n | 2D IoU | 2D BIoU 2% | BIoU-oracle 2% | lifted BIoU 2% | 2D BIoU 1% | lifted BIoU 1% |
|---|---:|---:|---:|---:|---:|---:|---:|
| found | 124 | 0.716 | 0.7595 | 0.7681 | 0.7146 | 0.7110 | 0.6383 |
| rank2 | 36 | 0.497 | 0.5364 | 0.5778 | 0.5132 | 0.4855 | 0.4472 |
| deep | 19 | 0.853 | 0.8714 | 0.8714 | 0.8355 | 0.8384 | 0.7753 |
| recall | 29 | 0.321 | 0.3818 | 0.4082 | 0.3229 | 0.3488 | 0.2685 |
| **全部** | 208 | 0.635 | 0.678 | 0.694 | 0.636 | 0.633 | 0.566 |

更直接的分层（按 2D best mask 的面积 IoU）：

| 2D mask 覆盖 | n | 2D BIoU 2% | lifted BIoU 2% |
|---|---:|---:|---:|
| IoU ≥ 0.5（mask 至少盖住物体） | 137 | **0.900**（中位 0.966） | 0.839（中位 0.897） |
| IoU < 0.5（没有一张 mask 盖住物体） | 71 | **0.252**（中位 0.174） | 0.245（中位 0.180） |

**结论**：0.678 主要不是“SAM 边界普遍很差”，而是 71 条查询（recall + rank2 为主）
连一张覆盖物体的 2D mask 都没有；在这 71 条上，2D 源本身确实不够。
在另外 137 条上，2D BIoU 已达 0.90（中位 0.966），边界不是主要瓶颈；
但 2D→3D→2D 仍损失约 0.06 BIoU，1% band 下只有 3.5% 的 found/deep 能达到 0.95。

## 3. 它和候选损失是什么关系

之前的诊断把问题归为“候选/实例生成”（recall 0.027、deep 0.66）。边界实验说明：

1. **两者高度耦合，但不是同一件事**：71 条低覆盖查询（recall + rank2）的 2D BIoU 只有 0.25，
   这些查询的边界差首先是因为没有 mask 盖住物体；修候选是前提。
2. **good mask 上仍有独立的 lift 损失**：137 条 IoU≥0.5 的查询，2D BIoU 0.900，
   lift 后 0.839，损失 0.061；1% band 下 found/deep 只有 3.5% 达到 0.95。
3. **它不被现有模块优化**：merge_proj 没有边界项；推理没有 2D 边界先验；评测只看 IoU。
4. **它是可观测量、可优化量**：BIoU 有明确数学定义，可做选择准则/精修目标/评测补充。

更准确的说法是：**候选损失是主因，边界/lift 损失是第二层；两者在 recall/rank2 上重叠，
在 found/deep 上边界损失独立存在但量级约 0.05–0.06 BIoU。**
把 0.678 当成“SAM 边界普遍只有 0.68”会误判问题；它主要是低覆盖查询的混合均值。

## 4. 可以怎么做（方法层面）

### 4.1 边界感知的 2D→3D 投影

- **边界带排除/降权**：mask 边界 d 像素内不参与特征池化（用距离变换）；
- **部分 mask 不直接丢弃**：ratio < 0.3 的 mask 用软权重保留，避免薄结构消失；
- **边界感知的 superpoint 分配**：按距离/边界概率加权，而不是整块 ratio；
- **多视角 mask 边界一致性**：用多视角 boundary 投票约束 superpoint 边界。

### 4.2 边界感知的 3D→2D 渲染/精修

- **2D mask 作为 trimap**：把选中候选的 3D 支撑投影到查询视角，与 2D mask 边界做
  graph cut / matting / level set，精修边界；
- **边界带高斯重加权**：边界附近的 Gaussian 用 2D mask 的 inside/outside 概率调整；
- **多视角边界共识**：多个视角的 mask 边界投射到 3D，投票决定边界 Gaussian；
- **边界感知的可见性/尺度**：边界处高斯尺度/不透明度对 splat 边界的影响。

### 4.3 边界感知的候选选择

- 候选分数加入 **2D-3D boundary consistency**：渲染 mask 与逐视角 2D mask 的边界一致性；
- 用 BIoU 作为 rerank/gating 的信号，而不是只用地 IoU；
- 评测同时报 IoU 和 BIoU，避免“面积对了、边界糊了”。

### 4.4 可借的方法/数学

- **Boundary IoU**（Cheng et al., CVPR 2021）：边界带定义与评测；
- **Boundary-aware segmentation**（Gated-SCNN、PointRend）：边界精修；
- **Graph cut / level set / matting**：trimap 边界精修；
- **Distance transform / signed distance field**：边界带权重、边界损失；
- **Optimal transport**：多视角边界匹配；
- **SAM/HQ-SAM**：更强的 2D mask 边界源。

## 5. 两个必须补的实验

1. **当前方法的 BIoU**：对 main / module C / gateE 的渲染 mask 算 BIoU（2%/1%），
   与 2D 按-IoU-best 上界（0.678/0.633）、2D BIoU-oracle（0.694/0.645）和
   lifted 上界（0.636/0.566）比较。
   如果 gateE 的 BIoU 已经接近 lifted 上界，说明边界损失主要来自 2D→3D→2D；
   如果远低，说明候选/掩膜选择也在损失边界。
2. **2D 边界精修**：对 gateE 选中的候选，用查询视角 2D mask 做 trimap + graph cut / matting，
   看 IoU/BIoU 是否提升；这是最便宜、最直接的边界改进。
3. **分层报告**：所有边界数字必须同时给 mean/median，并按 2D mask 覆盖率（IoU≥0.5）分层；
   否则 71 条低覆盖查询会把均值拖到 0.68，掩盖 found/deep 上 0.90 的实际情况。

---

## 6. 与“objectness/候选”方向的关系

- **不是二选一，但优先级不同**：候选缺失（recall/rank2）同时造成低覆盖和低 BIoU；
  边界/lift 损失在 found/deep 上独立存在，量级约 0.05–0.06 BIoU。
- 候选修复能把 recall 0.02→0.2；边界修复能把 found/deep 的 BIoU 从 ~0.84 拉近 2D 上界 ~0.90。
- 论文如果只做候选，会被问“边界为什么这么糊”；只做边界，会被问“recall 为什么这么低”。
- 最稳的叙事：**先 objectness（候选从哪里来），再 boundary-preserving 2D-3D-2D（掩膜怎么保真）**，
  两条都用 GT 量化头寸。

---

## 7. 一句话

**0.678 不是“SAM 边界普遍只有 0.68”：137 条有覆盖的查询 2D BIoU 已达 0.900（中位 0.966），
71 条低覆盖查询把均值拖到 0.252；候选缺失是主因，lift 在 good mask 上再损失约 0.06 BIoU。**
边界损失真实存在，但它主要与候选损失重叠，不是一条同等量级的独立主轴。
