# 我们真正解决了什么？——阶段反思（2026-10-31）

## 1. 直接结论

**没有完美解决，我们做的是“选择层的补丁”，不是“实例形成的解法”。**

- 已解决/改善：在**给定候选池**内，如何用物体级 mask 证据重排、如何保守 gating。
  结果 B0 0.6393 → **0.6760**（+3.7），deep 0.226→0.661，found 不降。
- 未解决：**物体实例从哪来、跨视角怎么关联、池里没有正确候选时怎么办**。
  证据：recall 族 29 条仍然只有 0.0198；增益集中在 deep（19 条）与 ramen；
  released pool 的 oracle 只有 0.7094，贪心联合 0.7500/0.7818——**上限不在排序，而在候选/实例集合**。

换句话说：我们把“已有的候选”选得更好了，但没有让系统**发现新的物体实例**，也没有真正解决
“同一物体的不同视角观测如何被认成同一个实例”。这是延缓与补充，不是根治。

## 2. 三个层次，我们只做到第一层半

| 层次 | 内容 | 我们的状态 |
|---|---|---|
| L1 选择 | 在固定候选池里重排/截断/gating | **已做**（mask rerank + gateE，+3.7） |
| L2 聚合 | 给定候选，如何聚合逐视角证据 | **部分**（物体级 top-3 优于一致性；但仍受候选支撑限制） |
| L3 实例形成与关联 | 文本无关的 3D 物体 proposal + 跨视角关联 | **未做**（recall 29 条无解；2D 上界 0.235 拿不到） |
| L4 语义打分 | 文本/校准/融合 | 已有基线，λ 仍敏感 |

## 3. 证据：真正的天花板在哪

1. **池内 oracle 0.7094**：即使每查询从池里挑最佳，也只有 0.709。我们 0.676 已接近池内上限的 95%。
2. **recall 29 条**：池内最佳候选 0.027；3D gateE 0.0198。重排/选择无论怎么改都救不了。
3. **2D 信息是存在的**：GT 最佳 2D mask 提升到 3D，deep 0.8247、recall 0.2352；
   但“选哪张 2D mask”做不好（text 0.529/0.108；几何 0.610/0.117；都远低于上界）。
4. **跨视角特征一致性不是关联信号**：用它选 mask 反而更差（text 0.4598 → xview 0.4003/0.3038，
   support-only 0.0251）——共享/背景 mask 更“一致”。
5. **几何是关联信号，但我们只拿它做打分**：几何约束把 2D 选择从 0.460 提到 0.526，
   支撑约束在最强候选上有效、全池支撑更差（0.453）——说明几何该用于**建立实例**，而不只是选 mask。

## 4. 真正值得挖的问题

**文本无关的 3D 物体实例发现 + 跨视角关联（class-agnostic objectness before semantics）。**

具体地：
- 节点：所有视角的 SAM mask（2D 物体候选，强且 lift 损失小）。
- 边：**几何兼容性**（lift 后的 Gaussian 支撑重叠/可见性），而不是特征一致性；
  特征相似度只作弱先验。
- 结构：在 mask 图上找一致的 mask track / 连通分量 / 谱聚类，得到一个 3D 实例。
- 语义：实例建好之后再用文本打分（而不是用文本决定候选生成）。
- 好处：直接解决 recall（池里没有的实例可以被发现）和 deep（正确 mask 的关联），
  并且把“文本相似度”从 proposal 阶段解耦出来——这是当前所有 patch 都绕不开的上限。

这与我们已有的证据完全一致：
- 2D mask 有信息（上界 0.825/0.235）；
- 一致性/背景会骗人（xview 失败）；
- 几何支撑是可靠的关联线索（几何选择 +6.6），但必须用于**链接**，不是只用于**打分**。

## 5. 哪些路是“补丁”，应该停

1. 继续调 λ / z 融合 / gating 规则：收益递减，且不解决 recall。
2. 继续在固定池里做 rerank：池内 oracle 0.7094，我们已到 0.676，空间有限。
3. 继续用文本/特征一致性选 2D mask：已被证明会选到共享 mask。
4. 继续把 2D proposal 硬 union 进 3D：found 会被拉低（0.585/0.650）。

## 6. 对论文定位的影响

- 现在的结果可以写成一篇**扎实的 incremental paper**：
  “一致性不是正确的不变量；物体级 mask 证据 + 保守选择可在不伤 found 的前提下修复 deep”。
  有诊断、有负结果、有门控，故事完整。
- 但它**不是**“解决了开放词汇 3D 分割的实例发现问题”。如果要在顶会讲成“problem solved”，
  必须做 L3：文本无关的 3D 实例发现与跨视角关联；否则审稿人会说“只是 reranking”。

## 7. 建议的下一阶段（一句话）

**停止在池内做选择，开始做“2D mask 图 → 3D 实例 track → 文本打分”的文本无关实例发现。**
这是唯一能把 recall 从 0.02 拉到 0.2、把 macro 从 0.676 推向 0.75 的路线。
