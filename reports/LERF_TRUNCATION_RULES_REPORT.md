# LERF-OVS 截断规则实验报告（证据门控，训练-free，LOSO）

日期：2026-10-30
协议：leave-one-scene-out。每个留出场景的规则阈值（τ、k）只用其余 3 个场景的平均 IoU 选择，然后在留出场景上评估；GT 仅用于评估与选参。
规则输入只有 GT-free 证据：候选屏幕面积（area_ratio）与每高斯平均观测次数（mean_vis）。
脚本：`lerf_truncation_rules.py`（GPU 渲染）、`lerf_rules_loso.py`（CPU 选参与汇总）。
数据：`lerf_rules_20261030/<scene>_rules.csv`。

## 1. 三个预先登记的规则族

- **R1 挑战者并入**：若 top-1 候选很小（面积 < τ）且存在面积 > k 倍的候选，则把证据分最高的挑战者并入 gap 前缀（多标签并集）。
- **R2 重排重截**：同一门控，把挑战者移到队首后重新执行 ga p 规则。
- **R3 剪枝**：在 gap 前缀内删除面积 < τ2 的候选（保留 top-1；全删则回退 top-1）。

阈值网格：τ ∈ {0.001, 0.002, 0.005}，k ∈ {2, 3}，τ2 ∈ {0.001, 0.002, 0.003}。

## 2. 主结果（场景平均 IoU，含全部 208 查询）

| 方法 | 场景平均 IoU | 说明 |
|---|---:|---|
| DeCo main（gap 多标签） | 0.6396 | 基线 |
| **R1（LOSO 选参）** | **0.6525** | **+0.0129**；四折均选 τ=0.001, k=2 |
| R2（LOSO 选参） | 0.6525 | 与 R1 等价（所选集合相同） |
| R3（LOSO 选参） | 0.6378 | −0.0018，剪枝无效 |

配对 bootstrap（按场景内重采样查询，4000 次）：**Δ = +0.0128，95% CI [+0.0007, +0.0279]**。区间刚过零，统计上为正但脆弱。

- **胜利全部是第 0 步诊断出的 rank_deep 查询**（正确候选在第 3–8 名、IoU 0.68–0.95 被 CLIP 排到末尾）：bowl、sake cup、bag——证据门控把"小而少被观测的 top-1 干扰片段"替换成真正的大物体，正是机制设计的目标。
- **失败集中在 porcelain hand 与 napkin**：类内小物体被大候选覆盖时，面积门控会误判（napkin 一条损失 −0.44，抵消了大半收益）。

规则按设计准确地作用于 cut_early（漏掉部件的查询，+11 个点），对 cut_late 无效（剪枝 R3 也无效），对正常查询有 −0.003 的轻微误伤。

## 5. 结论

1. **这是第一个训练-free、LOSO 验证下超过 DeCo main 的结果**（0.6396 → 0.6525，95% CI 刚过零），而且提升机制与诊断一致：门控识别 rank_deep，证据并入救回它们。
2. **增益集中在 ramen 和 cut_early 类查询**，简单场景零伤害——说明规则的行为可控、可解释。
3. **脆弱性必须如实说明**：只有 10 条查询被影响（5 胜 5 负，单次胜利 +0.68…+0.95，单次失败 −0.44），置信区间很窄地排除 0；napkin 型误判说明"面积/观测数"证据对小类内物体有系统性风险。
4. R2 与 R1 等价、R3 无效：收益来自"并入被漏掉的挑战者"，不是改变截断位置本身；削减（cut_late）方向缺少可用证据。

## 6. 下一步

1. **收紧误判**：给挑战者加 mean_vis 下限（被多视角充分观测）或要求 top-1 同时具备"小 + 少观测"，在 LOSO 下试 2–3 个预登记门控变体，目标是把 napkin/porcelain hand 类失败压掉。
2. **把同一规则搬到 ScanNet**（已有候选级证据表），验证跨数据集一致性。
3. **真正降低脆弱性**需要更多场景/种子（当前 4 场景、10 条受影响查询，统计强度有限）。
