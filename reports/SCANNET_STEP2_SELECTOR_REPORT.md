数据：认证 DeCo C1+C2 主链，`scannet_v2_certified_20261029`。
脚本：`step2_selector_experiments.py`、`step2_ablation_gate.py`、`step2_accuracy_diag.py`、`build_selector_features.py`。
产物：服务器 `deco-b123/step2_selector_20261030/`，本地 `scannet_seed1234_repro/step2_selector_20261030/`。

## 1. 设置

- 每个 root 的候选池 = 主分数 top-5 ∪ 全部 eligible 模式的 argmax 类（10 场景共约 1.1 万候选行）。
- 特征（全部无 GT、无场景先验）：
  - 分数形状：主分 s、deficit（相对 top-1）、全类排名 rank、is_top1；
  - 模式证据：模式票数、mode_score 最大值、advantage 最大值、M2 reliability、可靠性加权 advantage；
  - 多视角足迹：该候选模式足迹对 root 高斯的覆盖率、观察视图数、平均可见性、足迹模式数；
  - 几何上下文：root 高斯数、平均高度。
- 标签：class == root 的 GT 多数类（仅用于训练/评估）。
- 对照组：off（DeCo 原样）、λ 加权重排、logit、GBM、特征消融 A–D、概率差门控、两个 oracle 上界。

## 3. 增益的性质诊断（关键）

- **A 组（只有分数形状）**：mIoU +1.45，但 root 准确率下降 0.7pp——这是长尾重分配效应，不是更好的决策。
- **D 组（加入模式+足迹证据）**：mIoU +1.86，root 准确率 +3.6pp（净修复 62 个 root）。切换途中：切换到正确类别的 +130 个 root，把正确切成错误的 −68 个 root。
- 结论：**证据层（模式+多视角足迹）确实在改善逐 root 决策**，但单次切换的精度只有 26%，噪声很大；净收益来自"对的多于错的"。

## 5. 结论与下一步

1. **在 ScanNet 上，现有证据的选择器能兑现 +1.9 pooled（约上界的 9%），并且确实改善 root 决策（+3.6pp）**；但逐场景不稳、类间此消彼长，离"高提升"还差得远。
2. 纯分数启发式就能拿到 +1.4（但靠长尾重分配），说明 mIoU 这个指标本身会奖励重分配——论文里必须用 root 准确率来证明决策质量，不能只报 mIoU。
3. 概率差门控无效（δ=0），说明问题不在"切换太激进"，而在切换证据本身的判别力不足。
4. 下一步应做证据审计（第 3 步）：把 VALA 可见性与 ReLaGS MWP 做成候选级特征，先验证它们能否在 wall 混淆和 sink 混淆上提供正交判别力；同时给选择器加"场景级置信度/保守校准"以消除 scene0062 式的倒退。
