## 3. 关键诊断：ROFA 在本信号上是“近似空操作”

1. **剔除比例极小**：每查询平均剔除 4.4%–4.8% 的视角（中位 4.6%，最大 6.9%）；每候选平均 95 个覆盖视角，q_i 分布很紧，τ=2 的 μ-2σ 切点几乎不触发。
2. **查询视角从未被剔除**：1097 个候选中 query-view removed = 0（rofa 与 rofac 都是 0）。
3. **结论与是否关联无关**：208 条查询中有 **205 条** raw / rofa / rofac 的渲染 IoU 完全相同（其余 3 条只差 1 条 deep 查询，rofac 与 rofa 的 deep 0.3667 vs 0.3565 也只涉及该查询）。也就是说，**改进后的关联（center 空间一致性）对最终结果没有产生任何可测量的影响**；端到端的全部变化来自“用观测特征聚合分替换 NAG 排序”，而不是来自视角剔除。
4. **伤害呈系统性、按 prompt 聚集**：found 族里崩到 0 的 5 条是 figurines 的 3 条 `waldo` 与 teatime 的 2 条 `dall-e brand`；deep 族被救回的 3 条是 figurines 的 2 条 `pikachu` 与 1 条 `bag`。这不是“少数视角是离群点”，而是**观测特征对特定物体存在系统性混淆**。

## 4. 机理解释

- 观测特征是 root 区域掩码内 CLIP 特征的 beta 混合（region-level mixture），同一候选各视角共享区域语义，因此逐视角一致性天然偏高，ROFA 的离群剔除没有可剔除的对象。
- 即使剔除 5% 视角，95 视角的可见性加权均值变化在 1e-3 量级，而排序边际在 1e-2 量级（与此前 V2 截断上限 1.96 的诊断一致），不足以改变候选顺序。
- 因此 **ROFA 的有效性前提（视角间存在明显的离群观测）在 region 观测特征上不成立**；把同样的机制搬到 mask/segment 级也没有出现正向：Phase B 审计中段级一致性信号 Vc_seg 在 hard 上 AUC 0.759，但 found 保留率只有 0.597，作为重排分同样不可用。
- 这与 center_mv（S2_c 0.486 vs S2_raw 0.546）、F1/F1b（0.6225）一起，构成三条独立路线的收敛证据：**在现有 region/segment 观测特征上做聚合、一致性或重排，都无法在端到端超过 NAG 排序；代价集中在 found 族。**

## 5. 对“保留正确特征 / 去除噪声特征”的含义

- 去噪（剔除离群视角）不是瓶颈：数据里没有足够的离群视角可去。
- 保留正确特征也不能靠“换聚合权重/换排序”实现：found 族 124 条已经正确，任何以观测信号替换或融合 NAG 排序的方案都在这里付出代价（F1/F1b/本实验一致）。
- 剩下的、与排序解耦的 ReLaGS 机制是 **MWP（删低贡献高斯、直接改善掩膜质量）**：它不改候选选择，只改渲染掩膜，理论上对 found 族只增不减，是下一步应独立预注册的臂。
- 特征内容层面的改进必须来自 object-level 特征（逐 mask 2D 特征，已验证同物体跨视角 cosine 0.63–0.76、检索 top1 12–20%），并且必须以“只做加法、不替换 found 排序”的形式接入，否则会重演本实验与 Phase B 的 found 退化。

## 6. 判定

**ROFA 改进版（center 一致性 + 原空间聚合）不能有效改进 RoFA 路线；视角关联在本数据上不可作为涨点来源。** 建议关闭“region/segment 观测上的跨视角一致性”这一支，转入 MWP 与 object-level 特征两条独立线。
