# ScanNet 第 0 步失败归因报告（DeCo C1+C2 主链）

日期：2026-10-30
脚本：`/root/rivermind-data/repro/deco-b123/step0_scannet_attribution.py`、`step0_scannet_topk.py`
原始输出：服务器 `/root/rivermind-data/repro/deco-b123/step0_attribution_20261030/`（summary.md、stats.json、per_root.csv）；本地 `scannet_seed1234_repro/step0_attribution_20261030/`。

## 1. 方法与校验

- 数据：10 个测试场景，`scannet_v2_certified_20261029/ablation/v2_on_on/<scene>/predictions_and_scores.npz` 中的 `scores_off`（DeCo C1+C2 主分数，19 类 NYU40 子集）。
- 每个 root 取 GT 在 19 类内的多数类作为该 root 的答案；margin = 主分数 top-1 减 top-2。
- 一致性校验通过：off pooled 55.04 / macro 50.18，top-2 oracle pooled 64.31 / macro 60.58，与旧会话记录逐位一致。
- 有效 root 共 1730 个（1951 个 root 中有 221 个在 19 类内无有效 GT，跳过；旧记录中的 1951 是总 root 数）。

## 2. 总体构成

| 类别 | root 数 | 占比 |
|---|---:|---:|
| 正确（pred == GT） | 597 | 34.5% |
| GT 是 top-2（重排可救） | 202 | 11.7% |
| GT 不在 top-2（本步救不了） | 931 | 53.8% |
| GT 是 top-1 但 pred 丢了对的类 | 0 | 0% |

错误共 1133 个 root；其中 top-2 重排可救 202 个，占错误的 17.8%。

**重要结构事实：pred ≠ top-1 的比例是 0。** DeCo 在 ScanNet 上就是逐 root 的 argmax，不存在"gap 截断选错"的问题——ScanNet 侧的错误全部是排序错误，与 LERF 的 gap 截断问题是两回事。

## 5. 现有模式证据的覆盖

| 组 | GT 落在 V2 模式候选里 |

V2 已导出的模式候选只能覆盖不到一半的重排目标。选择证据层（第 3 步）不能只靠模式候选，必须引入正交证据（VALA 可见性 / ReLaGS MWP），并且要先审计这些证据在候选级上的可获得性。

## 8. 对计划的修订（基于本报告）

1. **ScanNet 侧的选择问题是 top-4/5 的浅层重排，不是 top-1/top-2 二选一。** 第 2 步子集选择的目标集合定为 top-k（k≈5，GT 覆盖 66.6%），top-2 只是其中一小块。
2. **纯阈值规则出局**：margin 分布重叠太深（0.01 阈值误伤 25% 正确 root）。必须用候选级证据做判别。
3. **模式候选不够用**（fixable 覆盖 46.5%）。第 3 步的可见性/MWP 证据是必要补充，且应先做一份候选级可获得性审计。
4. **强类别结构写进论文**：贴墙物体 vs wall、家具之间的混淆，是"判别需要多视角/空间证据"的故事线。
5. LERF 侧跑同口径归因后再合流（LERF 侧的缺口是 gap 截断 + 子集选择，两边的选择器可以共享一套候选级特征）。
