## 1. 模块定义（Learned Prefix Pruning + Scale-Gated Inclusion）

逐查询（released top-5 pool）：
1. **剪枝**：用冻结的 LOSO IoU 回归器（GBM；训练只用其他 3 个场景的 GT IoU 标签）预测每个候选的 IoU；在 released gap 前缀中，**删掉预测 IoU < 0.5 × max_pred 的非 top-1 候选**（top-1 永远保留）。
2. **置信守卫**：仅当 max_pred ≥ 0.5 时执行剪枝，否则保持 released gap 前缀。
3. **并入（R1 规则，常数沿用）**：若尺度门控触发（top-1 面积 < 0.001 且存在面积 > 2 倍候选），把尺度证据 A = z(area)+z(mean_vis) 最大的挑战者并入选择集。
渲染最终集合并精确评估。C0 = 去掉第 2 步守卫的诊断变体。

## 4. 与之前所有失败路线的关系

- 这不是又一个"零参数切换规则"：它只做**集合层**的删除/添加，错误代价是有界的（剪枝最多丢一个已选候选，并入最多加一块掩膜），避开了单候选切换的 −0.85/次灾难。
- 也不是纯参数调优：剪枝依赖 LOSO 学习到的候选质量预测（found 保留率 0.984 是关键），并入依赖尺度证据——两个组件各自都有预注册记录。
- 分布截断（D1-D4）、池深、阈值网格、单候选选择、纯证据融合全部未过门控；本模块是唯一通过冻结门控的。

## 5. 诚实的局限与验证要求

- **学习组件**：IoU 回归器只用训练场景 GT 标签（LOSO，逐折重训），但仍是监督信号；论文中必须披露。C0（无守卫）更高但为诊断变体，若采用需新的独立验证，不能事后改主结果。
- **样本强度**：4 场景 208 查询，CI 已排除 0 但宽度可观（+0.6% 到 +4.5%）；建议补多种子/更多场景。
- **跨数据集**：ScanNet 是单标签协议，剪枝/并入的多标签操作无法直接移植；该模块目前是 LERF/3D-OVS 多标签协议上的结果，需要按同一协议在更多场景验证。
- 20 条左右的损失查询集中在 rank2（−0.023），来源于并入/剪枝替换了本已正确的选择；后续可用守卫收紧，但属于在 4 场景上继续调，暂不做。
