## 1. 一句话结论

**一条原则、两个实例、两处精确零对照。**

- 原则：`S[g,c] = μ + a_g + b_c + r[g,c]` 的可加分解。在类别轴上做 argmax 时，行常数 `a_g`
  精确抵消；在候选轴上做 top-k 时，列常数 `b_c` 精确抵消。**校准必须与判决轴匹配。**
- 实例一（列轴）：ScanNet 的 C1 区域轴中心化 + C2 文本词表，40.79 → 58.55 pooled（+17.76）。
- 实例二（行轴）：LERF-OVS 的判决证书，0.6401 → 0.6711（+3.13，CI [+1.14,+5.48]）。
- 零对照：LERF-OVS 逐帧 9/9 上「行中心化 = plain」逐位相同；ScanNet 单查询 30/30 条上
  「减列偏置 `b_c` = 不处理」逐条相同。

**不能主张**：一个模块同时提升两个数据集。C1 在 ScanNet +12.88、在 LERF-OVS −0.08；
证书在 LERF-OVS +3.13、在 ScanNet −4.27、LERF-MASK 嵌套 −27.09、3D-OVS −6.54。
这个符号反转本身就是论文的证据，见 `tables/T2_operator_transfer.tex`。

| LERF-OVS 选项 oracle | 0.6751 | 审计器 0.6711 已用掉 **88.6%**；继续调门控上限约 +0.4pp |

3D-OVS 的四级分解是这一节最重要的证据，因为它把「复现差距」定位到了具体一层：

| 上限 | 单位 | bed mIoU |
|---|---|---|
| 逐高斯 oracle | 503k gaussians | **95.94** |
| level-0 簇 oracle | 7192 clusters | 92.45 |
| level-1 簇 oracle | 2211 clusters（特征最细层） | 77.35 |
| level-2 簇 oracle | 149 clusters | 77.76 |
| 当前文本选择 | level 2–3 | 61.24 |

逐高斯 oracle 与论文的 94.4 一致 ⇒ GT、相机、渲染、协议都对；差距在每视角 mask 数
（bed 53 / bench 412 / lawn 598 / room 72 / sofa 131，健康线 >100）。**在本管线内重编码无效**：
pps 32→64 后每视角区域数只从 53 到 57，文本选择反而 61.24→44.36。

## 5. Tier 3：已否证（论文的负结果表）

完整表 `tables/T6_negatives.tex`。按证据强度分三组：

**A. 结构性零结果（可证明，最适合写进正文）**

- 行中心化在 LERF-OVS 单查询上逐帧完全相同（0.639 = 0.639，9/9 帧）。
- 列偏置 `b_c` 在 ScanNet 单查询同 query 排序上 30/30 条完全相同（AP 0.5797 = 0.5797）。
- 白化 / Mahalanobis 0.639 → 0.459；bbox 保上下文 0.639 → 0.393；masked-max 池化 0.639 → 0.377。

**B. 方向错（有效应但符号为负）**

- VCLS 独立增益 +0.39，CI [−0.03,+0.82] 跨零 ⇒ 上界约 0.8pp。
- 局部对比 B0–B6 两个数据集全负；**随机参考与空间 kNN 几乎同分** ⇒ 损害来自「减掉一个参考均值」本身。
- 证书移植到闭集：ScanNet 50.18→45.91；3D-OVS 70.05→63.51；LERF-MASK 嵌套 0.7313→0.4604。
  原因是结构性的：`B ⊇ A ⇒ δ_v ≥ 0`，证书只能比较等大小集合。
- `a_g` 单独 +0.97，但叠加审计器单调破坏 0.6711→0.6564，deep 改判 6→0。

**C. 同一观测上重排，全部失败（第三次独立失败）**

- MMD 裁剪选择 0.639 → 0.557（救 2/12 最差，赔 20 条）。
- QTC 逐字实现 0.5548 → 0.4058；它的 CSLS 项在单查询里是每查询常数。
- 边界判据 J：ρ(J,IoU)=0.431 < ρ(score)=0.504，只赢 14/86；w 单调 ⇒ 测的是粗对比不是边界。
- 几何/可见性/跨尺度一致性描述子 0.09–0.47，全部低于 rank1 0.5565；`mwp_conf` AUC 0.465、
  `agree` 0.442 ⇒ **一致性先验在 OV-3D 上方向是反的**。

统一形态：**所有干预都是「救困难、伤容易」，无一 Pareto**。近平衡把正误候选交错在
0.02–0.03 的带里，任何移动都在这个带内重新洗牌。因此论文的落点应是「两轴引理 + 2×2 主图 +
精确零对照」，而不是再提一个选择器。

## 6. 机制事实（写进正文比再涨一个点更有价值）

| 事实 | 数字 | 含义 |
|---|---|---|
| 分数与范围几乎不相关 | corr(Δscore,Δarea)=+0.19；Δscore/ΔIoU=0.42；Δarea/ΔIoU=0.46 | 二者互补 |
| 二者相加仍低于并集 | z(score)+z(log area)=0.6079 vs rank1 0.5565；仍低于 0.6401 | 单候选读端的天花板 |
| 跨视角一致性是反向信号 | `mwp_conf` AUC 0.465、`agree` 0.442 | 一致性先验方向错 |
| 被错过的正确候选更大 | 面积 7×、可见视角 +36%、分数 −0.038 | 文本分数系统性偏好碎片 |
| 信息分布相反 | LERF 逐视角强；ScanNet 逐视角弱（E0 25.30 vs released 40.36） | 决定在哪一层融合 |
| 空渲染在官方读端只有 +1.50 | 单候选 +4.2 是伪影（V1 删不可见前缀 = 0.6401 逐像素相同）；V3 0.6524，5/208、全在 ramen | 18/208 官方预测渲染为空：10 条可选择救回、8 条覆盖缺陷 |
| 2D 候选选择才是主导损失 | 池内最好 0.885，CLIP top-1 0.603；42% 选到 IoU<0.5 | 不是 NMS、不是三维聚合 |

## 8. 已知缺口（必须如实写进论文或补充材料）

1. **3D-OVS 没有可部署模块。** 只有复现基线 70.05 与 oracle 诊断；本地 `results/` 下没有它的
   任何产物，全部 R3。不要把它包装成正向结果。
2. **ScanNet 官方锚点不可复现。** 58.55 依赖 shipped `clip_cache` 对应的 366 簇场；盘上 nag 是
   386 簇，重建后官方 scorer 只给 56.05 pooled / 49.89 macro，且 renorm 顺序翻转。锚点行 R3、
   重建行 R1，表里已分列。
3. **LERF-MASK 的两个正向模块都弱**：C1 +3.12 在 61 条里只动了 4 条；增量生长 +2.78 只来自
   1 个 prompt。只能进适用域讨论。
4. **LERF-OVS 的 4 个场景参与过设计**，不是 held-out；`0.6760` 含冻结 LOSO 学习器，
   只能当消融，不能当 training-free 主结果。
5. **ScanNet 与 OpenGaussian 不可直接比**：对方剔除 `sigmoid(opacity)<0.1` 的点并强制
   `pred=0 where gt=0`，我们没有做。
6. 脚本层面的缺口：`experiments/cvpr27_8h_discovery/srem_tail.py` 被截断不可运行；
   `REPRODUCE.md` 引用的 `run_axis.sh` 在仓库中不存在（真正的入口是 `analysis/run_*.sh`，
   且它们调用的是 `deco/lerf_ovs/<script>.py` 而不是 `analysis/<script>.py`）。
7. 20 个离线评测脚本把 Windows 路径硬编码为
   `C:\Users\TYY\Documents\ChatGPT\ZCY-4090\scannet_seed1234_repro`；结果不拷到这个目录，
   这些脚本会静默跳过输入。
