# LERF-OVS 2D/3D 特征区分度诊断报告

日期：2026-10-31
用途：汇报“同一物体跨视角相似度高、不同类相似度也高、2D 特征强而 3D 聚合后变弱”的实验证据。
性质：**机理诊断**，不是官方 mIoU。官方基线见文末“口径与有效性”。

---

## 1. 实验设置

- 数据：LERF-OVS 四场景（figurines / ramen / teatime / waldo_kitchen），22 张标注图、208 条查询。
- 2D 特征：每张图 level-3 SAM 分割掩码的 CLIP 特征 `language_features/{frame}_f.npy`，按绝对标签索引 `feat[L]`。
- 3D 特征：DeCo 逐视角观测特征（`observations_level3.npz`，区域掩码的 beta 混合）与 NAG 候选特征。
- GT 只用于“指认每一帧里该物体的掩码/最佳候选”，并计算评估 IoU；不参与任何特征选择。
- 余弦均为 L2 单位化后的余弦；所有中位数在“同物体跨视角对”上统计。

---

## 2. 同一物体跨视角 vs 不同类别（2D mask 特征）

每个场景：取每个标注帧中与该物体 GT IoU 最高的 level-3 mask，作为该视角的物体特征；
- same：同一类别在不同标注帧的特征两两余弦；
- diff：不同类别特征之间的余弦（每类最多取 2 个视角）。

| 场景 | same 中位数 | diff 中位数 | 间隔 | Fisher 分离度 | 跨视角检索 top1 | top3 | top5 | 对数 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| figurines | 0.734 | 0.495 | 0.239 | 2.199 | 35.5% | 88.2% | 90.9% | 110 |
| ramen | 0.629 | 0.563 | **0.066** | **0.615** | 24.9% | 50.6% | 60.7% | 346 |
| teatime | 0.759 | 0.496 | 0.263 | 1.746 | 41.5% | 77.2% | 79.5% | 224 |
| waldo_kitchen | 0.603 | 0.498 | 0.105 | 1.293 | 40.0% | 60.0% | 70.0% | 10 |

要点：

1. **同物体跨视角相似度高是合理的**：0.60–0.76。
2. **不同类别的相似度同样很高**：0.50–0.56，ramen 上间隔只有 **0.066**，Fisher 仅 **0.615**。
3. 因此“同物体近”本身不构成区分度；**类间基线太高**才是问题。ramen 的跨视角检索 top1 只有 **24.9%**。

---

## 3. 归一化/白化：能拉开几何距离，但破坏文本对应

对同一批 2D mask 特征做不同变换，重算 same/diff 与跨视角检索：

| 场景 | 变换 | same | diff | Fisher | 检索 top1 |
|---|---|---:|---:|---:|---:|
| figurines | raw | 0.734 | 0.495 | 2.199 | 35.5% |
| | view z-score | 0.459 | −0.025 | 2.513 | 50.0% |
| | ZCA 白化 | −0.009 | −0.009 | −0.118 | 4.5% |
| | view z + 白化 | 0.419 | 0.007 | 2.057 | **69.1%** |
| ramen | raw | 0.629 | 0.563 | 0.615 | 24.9% |
| | view z-score | 0.141 | −0.033 | **1.011** | 35.5% |
| | ZCA 白化 | −0.010 | −0.010 | −0.206 | 4.6% |
| | view z + 白化 | 0.152 | −0.014 | 1.007 | 43.9% |
| teatime | raw | 0.759 | 0.496 | 1.746 | 41.5% |
| | view z-score | 0.469 | 0.015 | 1.636 | 41.1% |
| | ZCA 白化 | −0.007 | −0.007 | −0.190 | 4.5% |
| | view z + 白化 | 0.357 | 0.091 | 1.112 | 65.6% |
| waldo | raw | 0.603 | 0.498 | 1.293 | 40.0% |
| | view z-score | 0.100 | 0.005 | 1.268 | 30.0% |
| | ZCA 白化 | −0.009 | −0.009 | −0.140 | 10.0% |
| | view z + 白化 | 0.144 | 0.011 | 1.204 | 50.0% |

同一批变换下，**文本检索（在该视角全部 mask 中找 GT 最佳 mask）** 的表现：

| 场景 | 指标 | raw | view z | ZCA 白化 | view z + 白化 |
|---|---|---:|---:|---:|---:|
| figurines | rank1 数量 / n | 39/56 | 34/56 | **3/56** | 0/56 |
| | top1 IoU | 0.614 | 0.543 | **0.050** | 0.000 |
| ramen | rank1 数量 / n | 33/71 | 26/71 | 8/71 | 3/71 |
| | top1 IoU | 0.296 | 0.264 | 0.079 | 0.022 |
| teatime | rank1 数量 / n | 42/59 | 38/59 | 8/59 | 8/59 |
| | top1 IoU | 0.603 | 0.566 | 0.117 | 0.128 |
| waldo | rank1 数量 / n | 15/22 | 12/22 | 5/22 | 2/22 |
| | top1 IoU | 0.481 | 0.407 | 0.155 | 0.073 |

结论：

- **白化确实把 same/diff 拉开**（Fisher 从 0.6–2.2 提高，但白化本身 Fisher 为负、检索崩塌），
  view z + 白化的跨视角检索 top1 可到 43.9–69.1%；
- **但它破坏文本对应**：白化后文本 rank1 从 39/56 掉到 3/56（figurines），top1 IoU 0.614→0.050；
  view z 也普遍降低文本 rank1 与 top1 IoU；
- **逐视角中心化（减去视角均值）几乎不改文本排序**：rank 变化 improve/same/worse =
  3/48/5、11/52/8、8/50/1、1/19/2，top1 IoU 0.614→0.616、0.296→0.295、0.603→0.598、0.481→0.475。
  这与“中心化在同一视角内是常数平移、不改变排序”的推导一致；但它改变跨视角聚合的分数。

## 4. 2D mask 特征本身的文本判别力

“GT 最佳 mask 在该视角全部 mask 中用文本相似度排第几”：

| 族（按 3D 候选池定义） | rank1 | 比例 |
|---|---:|---:|
| found (124) | 96 | **77.4%** |
| rank2 (36) | 14 | 38.9% |
| deep (19) | 11 | **57.9%** |
| recall (29) | 8 | 27.6% |
| **全部 (208)** | **129** | **62.0%** |

- found 族里 77.4% 的查询，**2D 特征直接就能把正确 mask 排到第一**；
- deep 族（3D 侧排第 3 名以后）也有 57.9% 在 2D 特征上是 rank1，说明 2D 特征携带了 3D 流程丢掉的信息。

## 5. 2D → 3D：提升损失很小，聚合损失很大

### 5.1 把 2D mask 直接提升到 3D

做法：选中 mask 内的 Gaussian（渲染权重 > 1e-4），用原渲染器渲染语义，与 GT 算 IoU。

| 场景 | 2D mask IoU（cov2d） | 提升到 3D 后 IoU | Δ |
|---|---:|---:|---:|
| figurines | 0.770 | 0.686 | −0.084 |
| ramen | 0.434 | 0.413 | −0.021 |
| teatime | 0.724 | 0.683 | −0.041 |
| waldo_kitchen | 0.705 | 0.636 | −0.069 |
| **全部 208 查询** | — | — | **−0.049** |

分族：found −0.050、rank2 −0.025、deep −0.028、recall −0.086。

**提升本身只损失约 5 个 IoU 点**，说明 3D 表示不是主要瓶颈。

### 5.2 聚合后的 3D 特征（候选级）

在 released top-5/6 候选池上，用各类 3D 特征做 argmax，看是否选中 GT 最佳候选：

| 3D 特征 | 场景平均 IoU* | found 命中 | rank2 命中 | deep 命中 |
|---|---:|---:|---:|---:|
| NAG score（原排序） | 0.5315 | 1.000* | 0.000 | 0.000 |
| `id_top3`（逐视角 top-3 均值） | **0.5453** | 0.863 | 0.528 | 0.526 |
| `id_mean_c`（中心化均值） | 0.5294 | 0.847 | 0.444 | 0.158 |
| `id_mean`（原始均值） | 0.4628 | 0.782 | 0.111 | 0.211 |
| `agree_c`（中心化跨视角一致性） | 0.3116 | 0.468 | 0.333 | 0.263 |
| `agree`（原始跨视角一致性） | 0.2301 | **0.315** | 0.333 | 0.211 |

*NAG score 的 found 命中为 1.000 是定义使然（found 族就是 NAG rank1 正确），不作为质量指标。
**左上列“场景平均 IoU”为图内查询平均后再跨图、跨场景平均，与官方 scene mIoU 口径一致。**

要点：

1. **跨视角一致性聚合（agree / agree_c）是退化最严重的部分**：found 命中从 2D 的 77.4%
   掉到 31.5% / 46.8%，场景平均 IoU 只有 0.2301 / 0.3116。
2. **简单均值聚合（id_mean_c）保留了大部分信息**：found 84.7%、场景平均 0.5294。
3. `id_top3` 在 rank2/deep 上最好（0.528 / 0.526），但那是另一个信号（逐视角 top-3 相似度），
   不是一致性。
4. 注意一个反直觉事实（逐查询平均）：**3D 最佳候选的 IoU（0.708）高于 2D 最佳 mask 的 IoU（0.635）**。
   3D 掩码可以比“最好的单个 SAM mask”更大、更完整，所以“3D 表示更差”只在
   **特征区分度/一致性聚合**这一层成立，在**掩码表示**这一层不成立。

### 5.3 为什么“提升到 3D 损失小”和“聚合后退化严重”不矛盾

两者是不同层次、不同输入、不同指标的实验：

| 实验 | 输入 | 是否用文本/特征排序 | 指标 | 回答的问题 |
|---|---|---|---|---|
| 2D→3D 提升 | **GT 选出的最佳 2D mask**（oracle） | 否 | 渲染 mask 与 GT 的 IoU | 3D 高斯能否表示这个掩码？ |
| 2D 文本排名 | 逐视角 mask 特征 | 是（无聚合） | GT 最佳 mask 的排名 | 单视角特征能否认出物体？ |
| 3D 聚合 | 逐视角观测特征 → 聚合 | 是（有聚合） | 候选命中率 / IoU | 聚合后的特征还能否认出物体？ |

- **提升实验是“给了正确答案”的上界**：已知哪块 2D mask 是对的，只测把它投影到 Gaussian 后还能不能画出来。
  结果 0.686–0.683 vs 2D 的 0.770–0.724，只掉约 0.05，说明**渲染/表示层不是瓶颈**。
- **聚合实验是“没给答案”的识别任务**：要从 5–6 个候选里靠聚合特征选出正确物体。
  这一步的损失来自特征混合与聚合，而不是渲染。
- 因此正确表述是：**几何表示没问题，语义身份在聚合时丢了。** 2D→3D 提升好，不等于聚合后的特征能区分实例。

一致性聚合（agree/agree_c）比简单均值（id_mean_c）差得多的原因：观测特征是区域掩码的混合，
“跨视角一致”更容易选中共享的区域/背景语义；剔除不一致视角，往往删掉的是物体最有辨识度的视角，
聚合结果反而更靠近场景公共成分。这与 ROFA/中心化在端到端上接近空操作的现象一致。

## 6. 结论（可直接用于汇报）

1. **同物体跨视角余弦高（0.60–0.76）是合理的**；真正的问题是**不同类余弦也高（0.50–0.56）**，
   ramen 上间隔只有 0.066，类间基线过高导致区分度低。
2. **2D 逐视角 mask 特征是最强的信号**：found 77.4%、deep 57.9% 的查询在 2D 上直接 rank1。
3. **2D→3D 的提升损失很小（−0.049 IoU）**，3D 表示不是瓶颈。
4. **损失发生在聚合**：跨视角一致性聚合（agree/agree_c）把 found 命中从 77.4% 拉到 31.5–46.8%；
   简单均值（id_mean_c）仍有 84.7%。**一致性聚合在混合特征上会稀释判别力，而不是增强它。**
5. **归一化/白化能拉开几何距离但破坏文本对应**：白化后文本 rank1 从 39/56 掉到 3/56，
   top1 IoU 0.614→0.050；view z 也伤文本排序。逐视角中心化对文本排序几乎无影响（208 条中绝大多数不变），
   但它改变跨视角聚合分数。
6. 因此改进方向应是：**保留 2D 逐视角特征的判别力，在关联空间做同实例分组，聚合时回到原始 CLIP 特征**；
   而不是在评分空间做白化/中心化，也不是用一致性分数直接替换文本相似度。

## 7. 口径与有效性

- 本报告数字来自 2D mask 特征与 DeCo 观测/候选的诊断脚本，属于**机理证据**（C 级），
  不是官方 mIoU，不能与论文表格直接比较。
- 官方读权基线（供对照）：
  - ReLaGS（C1 关闭）：63.29 / 51.15 / 80.97 / 60.62，macro **64.01**；
  - DeCo B0（C1 开启）：58.5869 / 51.8076 / 79.3896 / 65.9209，macro **63.9263**。
- 样本量：waldo 的同物体对只有 5 对（检索 n=10），其 same/diff/检索数字仅作参考。
- 2D mask 特征来自 VALA `language_features`；3D 观测来自 `observations_level3.npz`。两者均为可用产物，
  但与作者生成 `sai_nag.pt` 时的特征版本可能不同，因此只用于相对机理分析。
